# 《酒桌文化》游戏策划案

> **一句话概述**：一款以中国职场酒桌为背景的幽默策略对话游戏，玩家通过猜骰、选对话、点菜、选酒，在荒诞的职场应酬中一路升职加薪，从实习生喝到当老板。

---

## 0. 2026-10-16 本轮设定覆盖说明（当前执行依据）

### 0.0 双模式：上班咯 / 下班咯（本轮核心变更）

同一套 5 天流程，两种完全相反的「升职哲学」。**模式在开局时选定，整局不变。**

| 维度 | 💼 上班咯（onwork） | 🍻 下班咯（offwork） |
|------|--------------------|---------------------|
| 定位 | 职场正统玩法 | 下班解压玩法 |
| 一句话 | 小心应对，高情商发言 | 低情商怼人，反而平步青云 |
| 评分主导 | **好感度**（权重 0.35） | **尊严值/骨气**（权重 0.35） |
| 升职姿势 | 会做人、投其所好、照顾面子 | 敢说真话、敢怼、不给面子 |
| 翻车姿势 | 好感低、得罪人 | 唯唯诺诺、骨气低 |
| 猜骰赢的奖励 | 好感 +5 | 骨气 +5 |
| 晋升门槛 | Lv1-2:45 / Lv3-4:48 / Lv5-6:52 / Lv7-8:55 | Lv1-2:42 / Lv3-4:45 / Lv5-6:48 / Lv7-8:52 |
| 跨级 +2 条件 | 好感 ≥70、清醒 ≥60、尊严 ≥30、专业 ≥5 | 骨气 ≥70、清醒 ≥60、专业 ≥5 |

**设计意图**：把「同一场饭局、两种活法」做成一个开关。上班咯让玩家练情商，下班咯让玩家出气——两套数值权重相反，因此同样的对话选项在两个模式里是**完全相反的最优解**，重玩价值来自「换个模式重来一遍」。

**实现要点**：
- 模式存在 `State.mode`，取值 `"onwork"` / `"offwork"`，默认 `onwork`。
- 评分函数按模式取权重表：`GameData.PromotionModes[mode]`。
- 晋升主导属性用 `GameLogic.GetDriverValue()` 统一取（上班咯=好感 / 下班咯=尊严）。
- HUD 常驻显示当前模式，避免玩家忘记自己在玩哪个模式。
- 对话选择后，下班咯会额外给出「这话够硬气 / 太怂了」的即时反馈。

### 0.1 猜骰（比大小）替代大话骰（本轮核心变更）

**旧玩法（已废弃）**：大话骰·总和制 —— 双方各 1 颗骰，玩家轮流「加码叫点（2-12）」或「叫开」，比的是双方骰子总和。学习成本高，且「叫点递增」与「叫开判定」两条规则需要额外解释。

**新玩法（当前口径）**：**猜骰·比大小**

```
┌──────────────────────────────────────────────────────────┐
│  1. 双方各摇 1 颗骰（玩家看得见自己的点数，看不见对方的） │
│  2. 对手先选：他更大 / 他更小 / 一样大（以「预告」形式亮出）│
│  3. 玩家三选一：我更大 / 我更小 / 一样大                  │
│  4. 叫开亮骰：                                            │
│     · 玩家中、对手没中 → 玩家赢                           │
│     · 对手中、玩家没中 → 对手赢                           │
│     · 双方都中 / 都没中 → 平手，重摇一颗再选              │
└──────────────────────────────────────────────────────────┘
```

> **命名约定（重要）**：三个选项一律以「我 vs 他」表述，**不使用「大 / 小」这种无主语的写法**。
> 早期版本按钮只写「大 / 小 / 相同」，玩家看到「我方 5 点 / 对方 保密」时无法判断
> 「大」是"我大"还是"他大"，是明确的引导缺陷。现统一为：
> - 玩家按钮：**我更大 / 我更小 / 一样大**
> - 对手押注展示：**他更大 / 他更小 / 一样大**

| 项目 | 说明 |
|------|------|
| 玩家信息 | 只有自己的点数（可见）+ 对手押注的「预告」（可能为假） |
| 对手信息 | 对手先选，其选择**提前亮出**给玩家看 |
| 预告机制 | 越直爽的对手越容易被看穿（预告准确率高），越精明的对手越会藏 |
| 平局处理 | 双方点数相同 → 重摇并重新选择，**不消耗回合** |
| 胜负收益 | 玩家赢 → 获得本轮话语权（可打听明日情报）+ 主导属性 +5 |
| 失败代价 | 输 → 主导属性 -3 |

**对手性格与预告准确率**（`GameData.GuessDice.tellAccuracy`）：

| 性格 | 押注倾向（我更大/我更小/一样大） | 预告准确率 | 体感 |
|------|----------------------|-----------|------|
| 直爽豪迈 blunt | 0.55 / 0.30 / 0.15 | **80%** | 藏不住事，预告基本可信 |
| 谦虚务实 humble | 0.30 / 0.50 / 0.20 | 60% | 偏保守，爱押「我更小」 |
| 爱慕虚荣 vain | 0.45 / 0.35 / 0.20 | 55% | 爱押「我更大」 |
| 精明算计 shrewd | 0.30 / 0.35 / 0.35 | **40%** | 爱押「一样大」博高赔，且**经常骗你** |

**为什么这样改**：从「记规则 + 算概率」变成「读人 + 赌一把」。玩家只需要理解「我更大 / 我更小 / 一样大」三个选项，剩下的全是心理博弈——而且对手性格会真实影响预告的可信度，把 §2.5 的情报系统与骰桌串成了一条线。

**设计意图**：让不擅长算概率的玩家也能玩，同时保留「看穿对手」的策略深度。猜骰是「命运 + 读人」的双重博弈，而非纯数学题。

### 0.2 普瑞斯 / 普老板与乱入挑战者机制

- **普瑞斯，称呼"普老板"**，是**街机式隐藏挑战者**（参考街霸的豪鬼乱入）；不是 HR，也不是可玩角色"区域老板"。普通 HR 角色独立保留，继续使用 `hr`，不得用普老板替换。
- 普老板使用独立 NPC 资源 ID `pu_rui_si`；可玩区域老板仍为 `boss`。二者身份、立绘、头像、表情和对话资源不得混用。
- **普老板不是最终 Boss，也不是通关门槛**。她会在**任意一天（第2天起）**突然乱入，替代当天的常规对手。玩家通关不依赖是否遭遇她。
- **乱入条件（满足任一 + 35% 概率触发）**，见 §4.6：
  - `C1` 骰神附体：猜骰连胜 3 天（区域老板 2 天）
  - `C2` 廉酒识人：二锅头 ≥2 次 + 尊严峰值 ≥70
  - `C3` 硬骨头：硬刚选项 ≥4 次
  - `C4` 情商堪忧：尊严峰值 ≥85 + 好感峰值 ≤25
  - `C5` 过分周到：专业峰值 ≥40 + 好感峰值 ≥85
  - `C6` 醉后真言：醉酒时说过"想辞职"
- **击败挑战者的奖励**（非通关，是额外收益）：
  - 额外晋升 **+1 级**（可与当场晋升叠加）
  - 好感 **+10**、面子 **+20**、金钱 **+5000**
  - 每局只能被击败一次（`challengerDefeated` 后不再乱入）
- **乱入失败无额外惩罚**：按当天常规结算（升职/维持/降级/被优化）判定，不会因"没答好普老板的问题"而直接失败。
- **通关条件（统一，与普老板无关）**：最终日（普通第5天 / 区域老板第2天）结算为**升职**且职级达到 **Lv.8** → 判 `win`。
- 大股东 `npc_shark` 与创始人/CEO `npc_ceo` 保留，定位为**可扩展的前置精英对手**。
- 用户参考图当前归档为 `/workspace/assets/image/Art/References/pu_rui_si_reference.png`，修正标注后的版本为 `pu_rui_si_reference_final.png`。原图仅提供人物外观与画风依据；图内"林薇 / HR经理 / Lv.4 / 28岁"等旧标注不作为普老板的人设，不得照抄到游戏。外观取参考图，姓名与身份以本节为准。

**设计意图（街机乱入式）**：

| 维度 | 传统 Boss | 本作乱入挑战者 |
|------|----------|--------------|
| 出现时机 | 固定最终日 | 第2天起任意一天，随机 |
| 出现条件 | 必经 | 需玩家表现"扎眼"才触发 |
| 与通关关系 | 必须击败 | 完全无关，纯额外收益 |
| 玩家心态 | 压力、必须准备 | 惊喜、意外之喜 |
| 稀有度 | 100% 遇到 | 有条件 + 35% 概率 |

这样普老板成为**玩家玩出风格后的"彩蛋"**，而不是每次都要面对的例行关卡。

## 1. 游戏概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 《酒桌文化》 |
| 游戏类型 | 策略对话 / 猜骰决策 / 多分支剧情 |
| 游戏模式 | 💼 上班咯（高情商）/ 🍻 下班咯（低情商怼人）|
| 目标平台 | 移动端（竖屏/横屏均可，推荐横屏） |
| 美术风格 | 日系精细手绘，黑灰米白基底 + 黄紫重点色；以用户图及§0.3为准 |
| 核心受众 | 18-35岁职场人群，社畜共鸣向 |
| 游戏时长 | 单局 5-8 分钟，高重玩性 |
| 调性定位 | **幽默解压、荒诞讽刺、会心一笑**（绝不贩卖焦虑） |

### 1.2 设计理念

- **笑着活下去**：用夸张荒诞的幽默消解职场压力，让玩家在游戏里"社死"比在现实中"社死"开心一万倍
- **两种活法**：上班咯练情商，下班咯出恶气。同一场饭局，两套相反的最优解——想爽就开下班咯
- **每局不一样**：事件组合随机 + 多分支选择 = 极高重玩性
- **骰子是命运**：猜骰不是纯随机，而是"读人"——对手性格决定预告可信度，看穿他就能赢
- **社畜百态**：每个角色、每句台词都是职场人的"DNA动了"时刻

## 2. 核心玩法

### 2.1 游戏循环（核心 Loop）— 5天制

游戏总流程为 **5天**（工作日一周）。每场酒局 = 1天，但并非每天都有酒局——会随机触发"休息日"跳过一天。玩家从低职级起步，在有限的5天内尽可能升职，最终目标是**升到老板**。

```
┌───────────────────────────────────────────────────────────────┐
│  【首次开局】                                                  │
│  选择模式（上班咯 / 下班咯）→ 选择职场环境 → 选择初始角色      │
│       ↓                                                       │
│  ┌─────────────────────────────────────────────────────────┐  │
│  │ 【5天循环】                                              │  │
│  │                                                         │  │
│  │  第X天开始：                                            │  │
│  │  ├─ 正常酒局日：选饭局→选酒→点菜→猜骰+回合对话→结算     │  │
│  │  └─ 随机休息日："你不会觉得每天都有酒局吧？"           │  │
│  │       → 跳过一天，职级不变，日期+1                      │  │
│  │                                                         │  │
│  │  酒局结算 → 判定升职/维持/降职/被优化 → 日期+1          │  │
│  │  → 保存进度 → 进入下一天                                │  │
│  └─────────────────────────────────────────────────────────┘  │
│       ↓                                                       │
│  【终局判定】（5天结束 或 提前触发）                           │
│  ├─ 最终日升职且Lv.8 → 通关胜利                               │
│  ├─ 💀 累计被优化 2-3 次 → 游戏结束（失败）                  │
│  └─ ⏰ 5天用完 → 根据最终职级评定结局                         │
└───────────────────────────────────────────────────────────────┘
```

#### 5天时间线规则

| 规则 | 说明 |
|------|------|
| 每天 = 1场酒局 或 1个休息日 | 无论结果如何，日期都 +1 |
| 随机休息日 | 第2-4天之间随机触发1次（概率30%），弹出文案"你不会觉得每天都有酒局吧？今天摸鱼休息！"，职级保持不变 |
| 5天结束 | 不管是否升到老板，都进入最终结算 |
| 提前到Lv.8 | 继续后续日期；最终日结算为升职且保持 Lv.8 才通关 |
| 提前失败 | 累计被优化2-3次（根据起始职级调整），立即结束 |
| **普老板乱入** | 第2天起，满足条件时按 35% 概率乱入替代当日对手（非通关门槛，见 §4.6） |

#### 区域老板特殊规则（双局制）

选择**区域老板**角色时，游戏规则发生变化：

| 项目 | 普通角色 | 👔 区域老板 |
|------|----------|-------------|
| 总天数 | 5天 | **2天**（只需打2场酒局） |
| 起始职级 | Lv.1-5 | **Lv.7**（副总/合伙人） |
| 目标 | 最终日升职且达到Lv.8老板 | 同样须第2天升职并达到Lv.8 |
| 酒桌对手 | 随机同事/领导（普老板可能乱入） | 第1天随机，第2天随机或普老板乱入 |
| 失败条件 | 被优化2-3次 | **被优化1次即失败** |
| 难度定位 | 正常 | 🔥 Hard Mode |

**区域老板的2天酒局安排**：

| 天数 | 对手 | 说明 |
|------|------|------|
| 第1天 | 随机同事/领导 | 与普通角色相同的随机对手池，但对话难度更高（Lv.7级别） |
| 第2天 | 随机对手（普老板可能乱入） | 满足乱入条件（§4.6）时 35% 概率替换为普瑞斯（`pu_rui_si`） |

**隐藏挑战者与前置精英详情（2026-10-15 覆盖）**：

| 对手 | 特点 | 酒桌风格 / 当前定位 |
|------|------|----------|
| 普瑞斯（普老板） | 用户图所示角色，**街机式乱入挑战者**；非 HR、非可玩区域老板 | 第2天起满足条件时 35% 概率乱入（§4.6）；**击败给额外奖励，非通关门槛** |
| 大股东 | 掌握生杀大权，一句话决定你命运 | 保留为可扩展前置精英；高端白酒/洋酒，Tier 4场景，对话极其考验情商 |
| 创始人/CEO | 传奇人物，格局极大 | 保留为可扩展前置精英；风格不定，看重"气场"而非"排面" |

**乱入约束**：普老板乱入时按常规结算判定（升职/维持/降级/被优化），答不好不会直接失败。击败她额外获得晋升 +1、好感 +10、面子 +20、金钱 +5000，且每局只触发一次。

**设计意图**：
- 第1天是"热身局"，让玩家适应Lv.7难度的对话，同时积累面子值/好感度
- 第2天是"决胜局"，触发隐藏线则面对普老板，一局定生死
- 区域老板是"速通模式"/"挑战模式"，路径极短但容错为零，适合熟练玩家追求刺激
- **普老板是隐藏角色**：普通玩家可能整局都遇不到她，只有玩出"性格"的玩家才能解锁，制造稀有体验

#### 核心循环分层结构

游戏采用 **三层嵌套循环** 设计，保证每个时间尺度上都有明确目标与决策点：

**① 宏循环（Macro Loop）— 一整局（5天 / 5-8分钟）**

| 项目 | 内容 |
|------|------|
| 目标 | 从起始职级升至Lv.8（普老板为乱入挑战者，不影响通关） |
| 决策点 | 开局选择职场环境 + 角色 |
| 终局反馈 | 通关 / 永久优化 / 时间到评级 |
| 重玩驱动 | 9 个角色起始职级各异 + 随机事件组合 → 每局路径不同 |

**② 中循环（Mid Loop）— 一天（1场酒局，30-90秒）**

| 项目 | 内容 |
|------|------|
| 目标 | 本场酒局拿到"升职"判定 |
| 决策点 | 选饭局场景（Tier）→ 选酒类型 → 选酒品牌 → 6-10回合对话 |
| 终局反馈 | 升职/维持/降级/被优化 + 职级变化动画 |
| 资源投入 | 金钱（饭局+酒水）、面子值、清醒度 |

**③ 微循环（Micro Loop）— 一回合（5-10秒）**

| 项目 | 内容 |
|------|------|
| 目标 | 在本回合对话中做出最优选择 |
| 决策点 | 摇骰子 → 读取事件 → 4选1 |
| 即时反馈 | 数值条变化（好感/清醒/氛围）+ 骰子结果提示 + 音效 |
| 张力来源 | 骰子随机 + 选项后果不透明 |

#### 循环间的耦合关系（策略深度来源）

三层循环通过**资源流转**相互咬合：

| 上游决策 | 影响下游 | 具体机制 |
|---------|---------|---------|
| 宏：选角色 | 决定中循环起点 | 起始职级 → 决定可用 Tier 范围 |
| 宏：选职场环境 | 决定微循环内容池 | 专属事件触发（如"国企敬酒顺序"仅 state 环境出现） |
| 中：选饭局 Tier | 决定微循环难度 | Tier 越高 faceBonus 越高，但花费越高 |
| 中：选酒 | 决定微循环容错 | 面子值高 → 骰子加成；酒类型决定单次清醒度损耗 |
| 微：每回合选择 | 决定中循环结算 | 好感/专业度/氛围/清醒 → 综合评分 |

**核心张力**：金钱是有限资源，但"最贵的"不等于"最优的"——

- 高价酒（路易十三 ¥20000）给巨额面子值，但可能触发"太装了"的负面事件
- 廉价酒（牛栏山 ¥30）面子值极低，但配合"路边摊 + 高尊严值"可触发**反向收购**隐藏结局

#### 反馈机制设计

| 反馈类型 | 触发时机 | 表现形式 | 设计目的 |
|---------|---------|---------|---------|
| 即时反馈 | 每次选择后（<0.3秒） | 数值条动画 + 飘字（+5好感 / -20清醒） | 让玩家立刻知道选择后果 |
| 短期反馈 | 每回合结束 | 骰子胜负提示 + 事件文本更新 | 保持节奏感与悬念 |
| 中期反馈 | 每场酒局结束 | 结算页 + 职级升降动画 + 称号 | 提供阶段性成就感 |
| 长期反馈 | 整局结束 | 终局评定 + 每日记录回顾 + 称号收藏 | 驱动重玩 |

#### 节奏曲线（张力设计）

```
张力
 ▲
 │                              ╱╲   ← 终局爆发（Boss战/决胜局）
 │                        ╱╲  ╱  ╲
 │              ╱╲      ╱  ╲╱    ╲
 │        ╱╲  ╱  ╲   ╱            ← 休息日低谷（喘息）
 │  ╱╲  ╱  ╲╱    ╲ ╱
 │╱  ╲╱            V
 └──────────────────────────────────→ 时间
   Day1  Day2  Day3  Day4  Day5
  (热身) (适应) (休息) (冲刺) (决胜)
```

- **Day1**：教学期，事件简单，容错高
- **Day2-4**：难度爬升 + 随机休息日制造节奏落差
- **Day5**：决胜日，若差 1 级则触发"最后机会"高压氛围
- **区域老板**：Day1 热身 → Day2 直接 Boss 决胜，全程高压无低谷

#### 玩家动机循环（心流模型）

```
     ┌──────────────────────────────────────┐
     │                                      │
     ▼                                      │
  明确目标 ──→ 做出选择 ──→ 立即反馈 ──→ 数值成长
 (升到老板)  (选酒/选对话) (数值条+音效)  (职级+1)
     │                                      │
     └────────────── 新挑战 ◄───────────────┘
              (更高职级 = Tier更高 = 更难)
```

**心流保障**：

- 难度随职级自动提升（`难度惩罚 = 当前职级 × 3`），避免"越玩越简单"
- 单局 5-8 分钟，契合移动端碎片时间
- 失败不惩罚（可立即重开），鼓励"再来一把"

### 2.2 职级晋升系统

#### 职级阶梯（从低到高）

| 层级 | 职级 | 初始资金 | 解锁场景 | 描述 |
|------|------|----------|----------|------|
| Lv.1 | 🆕 实习生 | ¥500 | Tier 1 | 什么都不懂但什么都想学 |
| Lv.2 | 🐴 打工牛马 | ¥2000 | Tier 1 | 社畜本畜，卑微但有梗 |
| Lv.3 | 🎨 专业岗（设计/程序/销售等） | ¥5000-12000 | Tier 1-2 | 有一技之长 |
| Lv.4 | 📋 小组长/产品经理 | ¥8000 | Tier 2 | 开始管人了 |
| Lv.5 | 🧚 项目经理/主管 | ¥15000 | Tier 2-3 | 夹心饼干，上下都要哄 |
| Lv.6 | 📊 部门经理/总监 | ¥30000 | Tier 3 | 有实权了，但责任也大 |
| Lv.7 | 👴 副总/合伙人 | ¥50000 | Tier 3-4 | 距离顶峰一步之遥 |
| Lv.8 | 👔 **老板** | ¥100000 | Tier 4 | 最终日升职且保持此职级即通关 |

#### 晋升/降职规则

每场酒局结算后，根据综合表现判定。**「表现好」的定义由模式决定**：

| 结果 | 上班咯（好感主导） | 下班咯（骨气主导） | 效果 |
|------|-------------------|-------------------|------|
| ⬆️ **升职** | 好感度高 + 面子足 + 没醉到失态 | 骨气足 + 敢怼 + 没醉到失态 | 通常+1；满足跨级条件时+2 |
| ➡️ **维持** | 各项中等，没出大错也没亮点 | 各项中等，不功不过 | 职级不变 |
| ⬇️ **降职** | 好感低 / 踩到雷区 / 表现差 | 太怂 / 骨气低 / 表现差 | 职级 -1（最低 Lv.1）|
| 💀 **被优化** | 严重失态 / 好感极低 / 醉到失控 | 严重失态 / 骨气极低 / 醉到失控 | 优化计数 +1，职级 -1 |

#### 评分公式（按模式切换权重）

```
score = 主导属性 × 主导权重 + 次要属性 × 次权重
      + 面子 × 面子权重 + 氛围 × 氛围权重 + 专业 × 专业权重
      + (清醒 / 100) × 15 − 当前职级 × 3
```

| 权重项 | 💼 上班咯 | 🍻 下班咯 |
|--------|----------|----------|
| 好感 favor | **0.35** | 0.05 |
| 尊严 dignity（骨气） | 0.05 | **0.35** |
| 面子 face | 0.20 | 0.15 |
| 氛围 vibe | 0.15 | 0.15 |
| 专业 pro | 0.15 | 0.10 |

> KTV 续场触发时，**主导属性**的贡献 ×1.5（上班咯加成好感，下班咯加成骨气）。

#### 跨级晋升条件（2026-10-16 运行口径）

普通角色升职所需 `score` 门槛按**当前职级**取值，并**按模式给两套**：

| 职级区间 | 💼 上班咯门槛 | 🍻 下班咯门槛 |
|----------|--------------|--------------|
| Lv.1–2 | 45 | 42 |
| Lv.3–4 | 48 | 45 |
| Lv.5–6 | 52 | 48 |
| Lv.7–8 | 55 | 52 |

跨级晋升（+2 级）须同时满足：

| 条件 | 💼 上班咯 | 🍻 下班咯 |
|------|----------|----------|
| score | ≥ 本职级门槛 | ≥ 本职级门槛 |
| 主导属性 | 好感 ≥ 70 | 骨气（尊严）≥ 70 |
| 清醒度 | ≥ 60 | ≥ 60 |
| 尊严值 | ≥ 30（保底） | 无额外要求 |
| 专业度 | ≥ 5 | ≥ 5 |

满足则本场**晋升+2级**，最高到Lv.8；未满足全部跨级条件时仍按升职/维持/降职/被优化判定，升职通常+1。

此规则让普通角色在5天内可从Lv.1升至Lv.8，但不保证通关，休息日与实际酒局成绩仍影响路径。**区域老板每次升职恒+1，不适用跨级+2**。所有角色提前达到Lv.8仍继续，只有在最终日结算为升职并保持 Lv.8 才`win`。

#### 失败条件

| 角色类型 | 失败条件 |
|----------|----------|
| 普通角色（Lv.1-5起始） | 累计被优化 **3次** → 游戏结束 |
| 区域老板（Lv.7起始） | 被优化 **1次** → 游戏结束 |
| 所有角色 | 普通第5天/区域老板第2天结束，未满足“最终日升职且达到Lv.8” → 时间到评级 |

#### 进度保存

每天结束后自动保存：

```
存档数据 = {
    职场环境,          -- 开局选择后固定不变
    当前角色,          -- 决定特殊能力和起始职级
    当前天数,          -- 1~5（区域老板为1~2）
    当前职级,          -- Lv.1 ~ Lv.8
    累计被优化次数,    -- 普通角色0/1/2，区域老板0
    已完成酒局数,      -- 实际打的酒局场次（排除休息日）
    累计金钱,          -- 总收入
    解锁的称号[],      -- 成就记录
    历史记录[],        -- 每天的简要结果（含休息日）
}
```

### 2.3 每日流程

每一天的流程：

```
第X天开始
    ↓
系统判定：今天是酒局日还是休息日？
    ↓
┌─ 休息日（随机触发，概率30%，第2-4天之间最多1次）──┐
│  弹出："你不会觉得每天都有酒局吧？"              │
│  → 显示摸鱼动画 → 职级不变 → 日期+1              │
└──────────────────────────────────────────────────┘
    或
┌─ 酒局日 ─────────────────────────────────────────┐
│  选择饭局场景（根据当前职级解锁不同Tier）          │
│      ↓                                            │
│  选酒（类型→品牌）→ 点菜                          │
│      ↓                                            │
│  ┌─────────────────────────────┐                  │
│  │ 循环回合（6-10回合/局）：    │                  │
│  │  双方摇骰子 → 触发事件      │                  │
│  │  → 对话选择（3-4选项）      │                  │
│  │  → 结算本回合影响           │                  │
│  └─────────────────────────────┘                  │
│      ↓                                            │
│  本局结算 → 升职/维持/降职/被优化                  │
└──────────────────────────────────────────────────┘
    ↓
日期+1 → 保存进度 → 判断是否终局
    ↓
├─ 已达5天 / 已通关 / 已失败 → 进入最终结算
└─ 否则 → 进入下一天
```

**关键设计**：
- 模式和职场环境、角色一样，在开局时选定，5天内**不再重选**
- 每个新酒局日只需要选择**饭局场地**和**酒水**
- 休息日是"喘息机会"，给玩家制造节奏变化和悬念（"还剩几天？够不够升职？"）
- 区域老板没有休息日（2天全是酒局，紧张刺激）
- 5天制让每一局选择都更有**紧迫感**和**策略权重**

### 2.4 猜骰机制（比大小）

每回合开局插入一轮**猜骰**，决定本回合**话语权归属**。这是回合制的核心博弈环节。

#### 基本规则

| 项目 | 规则 |
|------|------|
| 骰子 | 双方各 1 颗。玩家**可见自己**的点数；**对手点数全程隐藏**（显示 `?`） |
| 对手先选 | 对手从「他更大 / 他更小 / 一样大」中先选一个，**选择以「预告」形式亮出**给玩家看 |
| 玩家后选 | 玩家三选一：「我更大 / 我更小 / 一样大」 |
| 叫开 | 玩家选完立即亮骰比对 |
| 判定：玩家中、对手没中 | **玩家赢** |
| 判定：对手中、玩家没中 | **对手赢** |
| 判定：双方都中 / 双方都没中 | **平手** → **重摇再选**（不偏袒任何一方） |
| 兜底 | 连续平手达 6 次（`maxRerolls`）时判对手胜，避免死循环 |

> ⚠️ **核心原则：只有一方押中才算分出胜负。**
> - 不能按「谁点数大」判胜负 —— 押错就是押错。
> - 不给「玩家后押占优」的偏袒 —— 双方看法一致（都中/都错）就是平手。
> （2026-10-16 两次修复：先删除「按点数大小判胜负」的错误兜底，再删除「都押中判玩家赢」的偏袒。）

#### 各场景判定速查

| 你的点数 | 他的点数 | 你选 | 他选 | 结果 |
|---------|---------|------|------|------|
| 5 | 2 | 我更小 | 一样大 | 都错 → **平手重摇** |
| 5 | 2 | 我更大 | 一样大 | 你中他没中 → **你赢** |
| 5 | 2 | 我更大 | 他更小 | 都中 → **平手重摇** |
| 1 | 6 | 我更小 | 他更大 | 都中 → **平手重摇** |
| 3 | 3 | 一样大 | 一样大 | 都中 → **平手重摇** |
| 3 | 3 | 我更大 | 我更大 | 都错 → **平手重摇** |
| 1 | 6 | 我更大 | 我更大 | 你错他对 → **他赢** |

#### 「预告」与「真实选择」的区别（重要）

| 概念 | 含义 | 玩家可见 |
|------|------|---------|
| **预告** `tellChoice` | 对手「说」自己押什么，**可能为假** | ✅ 显示在骰桌中央与状态行 |
| **真实选择** `opponentChoice` | 对手实际押注，决定胜负 | ❌ 仅叫开亮骰后公布 |

> ⚠️ **状态行必须引用预告，绝不能写真实选择**，否则等于提前泄露答案（2026-10-16 修复：
> 曾出现顶部显示预告「他更小」、状态行却显示真实选择「一样大」的自相矛盾）。
> 预告在摇骰时**一次性生成并落库**，界面重绘/重进都读同一个值，不会前后变化。

#### 「一样大」怎么算

- 选「一样大」= 赌双方点数相同。
- 双方点数**真的相同** → 选「一样大」者押中。
- 双方点数**不同** → 选「一样大」必输。
- 双方点数相同但**没人选「一样大」** → 都没中，重摇。

#### 选项文案规范（引导要求）

| 位置 | 文案 | 说明 |
|------|------|------|
| 玩家按钮 | **我更大 / 我更小 / 一样大** | 必须带主语「我」，明确是我方点数 |
| 对手押注展示 | **他更大 / 他更小 / 一样大** | 同一参照系，方便与自己的选择直接对比 |
| 骰桌顶部 | "赌的是「你的点数」和「他的点数」谁大 —— 你看不到他的点数。" | 首次进入时的规则说明 |

> ⚠️ **禁止**使用「大 / 小 / 相同」这类无主语写法。玩家只能看到自己的点数，无主语的「大」无法判断指谁，会造成引导缺陷（2026-10-16 修复项）。

#### 对手的「预告」机制（核心信息源）

对手先押，其选择会亮出——但玩家看到的是**预告**，预告可能为假：

| 对手性格 | 预告准确率 | 体感 |
|----------|-----------|------|
| 直爽豪迈 blunt | 80% | 藏不住事，他说押什么基本就是什么 |
| 谦虚务实 humble | 60% | 比较实诚，偶尔藏一手 |
| 爱慕虚荣 vain | 55% | 一半一半，看运气 |
| 精明算计 shrewd | 40% | **经常骗你**，得反着想 |

> 预告的准确率来自 `GameData.GuessDice.tellAccuracy`；押注倾向来自 `personalityBias`。
> 也就是说：**情报系统（2.5）拿到的「明日对手性格」，直接决定了猜骰该怎么读。**

#### 话语权的收益

| 结果 | 上班咯 | 下班咯 |
|------|--------|--------|
| 玩家赢（获得话语权） | 好感 **+5** | 骨气（尊严）**+5** |
| 玩家输（失去话语权） | 好感 **-3** | 骨气（尊严）**-3** |

两种模式都同样获得**询问一个情报问题**的机会（见 2.5）。

#### 设计意图

- **低学习成本**：只需要理解「我更大 / 我更小 / 一样大」三个选项，不需要记概率表或叫价规则
- **不完全信息博弈**：自己点数已知，对手点数未知，但对手的**押注**暴露了信息
- **读人 > 算数**：性格决定预告可信度，所以「先打听情报、再上骰桌」形成策略闭环
- **平局重摇**：避免「一样大」这种模糊结果，规则干净利落

#### 隐藏机制

- **面子值影响**：面子 > 20 时有 20% 概率让玩家骰子 +1，形成正向反馈
- **酒友奖励**：连续 3 次干杯事件都选喝 → 骰子永久 +1（整局有效）
- **猜骰连胜**：连胜 3 天（区域老板 2 天）会触发普老板乱入条件 C1

### 2.5 情报系统（话语权闭环）

赢得话语权后，玩家可向对手**询问一个情报问题**（每场最多 1 次），获得对手性格的**隐晦片面**信息，**供次日**选择参考。

#### 问题抽取机制（2026-10-16 更新）

问题库扩至 **17 个**，每场随机抽 **4 个**给玩家选，抽到的题不固定：

| 类型 | `kind` | 数量 | 说明 |
|------|--------|------|------|
| **有价值** | `value` | 10 | 能问出明日对手的真实偏好，问了有用 |
| **闲聊** | `fluff` | 7 | 纯聊天，**问了拿不到情报** |

**抽取规则**（`GameLogic.RollIntelOffers`）：
- 每轮**至少抽 2 个**有价值问题（`IntelMinValue`），保证玩家有判断余地
- 其余名额从闲聊问题里补，最多占（总数 − 2）个
- 每天重新抽一次，避免每天都见到同样的题

**有价值问题（10 个）**

| 维度 | 问题示例 |
|------|---------|
| 酒 | 今晚想喝点什么？ / 喝酒您有什么讲究吗？ |
| 菜 | 有什么忌口或偏爱？ / 您点菜一般什么原则？ |
| 场地 | 平时喜欢去哪儿吃？ / 更喜欢包间还是大堂？ |
| 预算 | 这顿想控制在什么档次？ / 花钱这事您怎么看？ |
| 性格 | 您是个什么样的人？ / 要不聊聊您自己？ |

**闲聊问题（7 个，问了白问）**

今天天气不错哈？ / 您平时看球吗？ / 过来路上堵不堵？ / 周末有什么安排？ / 您老家哪儿的？ / 您什么星座的？ / 您平时喝咖啡还是喝茶？

> **设计意图**：让「问什么」本身成为一次判断。闲聊问题各性格只给一句敷衍回应
> （如「嗯……还行吧。」），标签显示「无关信息」，且**不写入情报** ——
> 次日无法据此投其所好，等于白浪费这次话语权。

#### 四种性格与偏好档案

| 性格 | 场地偏好 | 酒价偏好 | 菜价偏好 | 行为倾向 |
|------|---------|---------|---------|---------|
| 爱慕虚荣 `vain` | 高 Tier | 高价 | 高价 | 排面至上 |
| 谦虚务实 `humble` | 低 Tier | 低价 | 低价 | 看重实在 |
| 直爽豪迈 `blunt` | 不限 | 高价 | 高价 | 讨厌客套 |
| 精明算计 `shrewd` | 低 Tier | 低价 | 低价 | 性价比优先 |

#### 情报闭环（选对 → 加成）

情报**只在所指向的那一天有效**，过期作废。次日选择若符合对手偏好，触发加成：

| 判定 | 效果 |
|------|------|
| ✅ 投其所好（选对） | 好感 **+6**、氛围 **+5**、面子 **+3** |
| ❌ 没踩在点上（选错） | 好感 **-4**、氛围 **-3** |

**判定口径**

| 选择类型 | 高价档 | 低价档 |
|---------|-------|-------|
| 场地 | Tier 3-4 | Tier 1-2 |
| 酒 | 单价 ≥ ¥300 | 单价 < ¥300 |
| 菜 | 单价 ≥ ¥300 | 单价 < ¥300 |

#### 性格日程机制

- 开局时**预生成**整局的每日性格序列（`personalitySchedule`）
- 今日情报询问的是**明日对手**的性格 → 情报真的有预测价值
- 玩家需自行推断"该点贵酒还是便宜酒"，判断错了次日仍会吃亏

### 2.6 对话选择系统

每次对话提供 3-4 个选项，风格分类：

| 风格类型 | 示例 | 效果倾向 |
|----------|------|----------|
| 🐴 职场马屁 | "张总这格局，我学一辈子都学不来" | +好感度，-尊严值 |
| 🔥 阴阳怪气 | "可不嘛，毕竟您工资是我十倍" | -好感度，+尊严值，可能触发隐藏线 |
| 🧠 行业黑话 | "这个我们要拉齐一下颗粒度" | +专业度，对方可能懵逼 |
| 🍺 酒桌套路 | "感情深一口闷，感情浅舔一舔" | +氛围值，-清醒度 |
| 😶 沉默摸鱼 | "嗯嗯，对对对，您说得对" | 中性，保命但无功无过 |
| 💀 整活发疯 | "不好意思，我要去厕所哭一会儿" | 随机效果，可能大加分或直接结束 |

### 2.7 数值系统

#### 核心属性（隐藏，结算时揭晓）

| 属性 | 说明 | 影响 |
|------|------|------|
| 好感度 | 对方对你的印象 | 直接影响结局走向 |
| 尊严值 | 你还剩多少自我 | 影响结局称号和隐藏剧情 |
| 清醒度 | 你还能正常说话吗 | 低于阈值触发"醉酒模式"（选项变乱） |
| 氛围值 | 饭局整体气氛 | 影响事件触发概率 |
| 面子值 | 场面功夫做得如何 | 受选酒、选餐厅影响 |

#### 金钱系统

- 初始资金根据角色不同（打工人 ¥2000 vs 区域老板 ¥50000）
- 选餐厅、选酒、点菜都要花钱
- **钱花得多不一定好**（可能被认为"不会过日子"或"太装"）
- **钱花得少也不一定差**（可能被认为"务实"或"抠门"）
- **预算不足处理（当前运行）**：当余额无法负担任何完整酒局套餐时，玩家可手动“结束当日”，按`optimized`（被优化）结算并推进日期；沿用优化计数与失败上限，不提供充值或充值补差流程。
- 结算时剩余金额影响评分

### 3.2 初始角色（决定起始职级与特殊能力）

玩家开局选择角色，决定**起始职级**和**贯穿全程的特殊能力**。资金由当前职级决定（见 2.2 职级阶梯），角色不影响资金。

| 角色 | 起始职级 | 特殊能力（全程有效） | 描述 | 晋升难度 |
|------|----------|----------------------|------|----------|
| 🆕 实习生 | Lv.1 | "萌新光环"：每场酒局第一次失误不扣好感 | 什么都不懂但什么都想学 | ★☆☆☆☆（路最长但容错高） |
| 🐴 打工牛马 | Lv.2 | "已读不回"：每场可跳过一次强制对话 | 社畜本畜，卑微但有梗 | ★★☆☆☆ |
| 🎨 设计师 | Lv.3 | "五彩斑斓黑"：对话中可解锁隐藏创意选项 | 需求听不懂但画得出来 | ★★★☆☆ |
| 🔧 程序员 | Lv.3 | "Debug"：清醒度下降速度减半 | 高薪但社恐，喝多了可能写代码 | ★★★☆☆ |
| 🎤 销售冠军 | Lv.3 | "话术王"：好感度增减幅度 ×1.5 | 能把梳子卖给和尚，也能把自己喝进医院 | ★★★☆☆ |
| 📊 HR | Lv.3 | "背调"：每场可查看对方一个隐藏属性 | 笑里藏刀，信息就是武器 | ★★★☆☆ |
| 📋 产品经理 | Lv.4 | "需求变更"：每场可推翻一次已选选项重选 | 永远在改需求，包括改自己说过的话 | ★★★★☆ |
| 👴 老油条 | Lv.5 | "太极推手"：每场可将一个负面效果转嫁 | 在公司活了二十年的终极形态 | ★★★★★ |
| 👔 **区域老板** | **Lv.7** | "我请客"：可强制买单提升全场面子值+20 | 🔥 Hard Mode：仅2天，普老板可能乱入 | ★★★★★★（极难） |

**设计意图**：
- 起始职级低 = 路更长（5天），但容错率高（可被优化3次）
- 起始职级高 = 离老板更近，但对话难度更高、对手更强、升职条件更苛刻
- **区域老板** = 速通挑战模式：仅2天、仅2场酒局、对手为隐藏Boss、被优化1次即失败
- 特殊能力贯穿全程，是角色差异化的核心体验

## 4. 结局系统

### 4.1 单局结算（每场酒局结束后）

每场酒局结束后根据综合属性判定**本局结果**，影响职业晋升进度：

| 结果 | 条件 | 表现 | 职级影响 |
|------|------|------|----------|

### 4.6 普老板乱入机制（街机式隐藏挑战者）

普老板**不是最终 Boss，也不是通关门槛**。她是**街机式乱入挑战者**——参考街霸的豪鬼，只有玩家表现"过于扎眼"时才会突然闯入。

#### 乱入条件

| 条件编号 | 名称 | 触发要求 | 设计意图 |
|---------|------|---------|---------|
| `C1` | 骰神附体 | 猜骰**连胜 3 天**（2天局为 2 天） | 手气太好，她想试试你 |
| `C2` | 廉酒识人 | 累计选"牛栏山二锅头" ≥ 2 次，且尊严峰值 ≥ 70 | 你太有性格了，引起了她的注意 |
| `C3` | 硬骨头 | 选择"说人话 / 劳动法 / 拒绝"类硬刚选项 ≥ 4 次（2天局 ≥2） | 不给面子，反而被记住 |
| `C4` | 情商堪忧 | 尊严峰值 ≥ 85 且好感峰值 ≤ 25 | 得罪人得罪到出名 |
| `C5` | 过分周到 | 专业峰值 ≥ 40 且好感峰值 ≥ 85（2天局专业 ≥20） | 太会做人，反而可疑 |
| `C6` | 醉后真言 | 醉酒事件中选过"我想辞职很久了" | 她听到了你的真话 |

#### 乱入判定流程

| 项目 | 规则 |
|------|------|
| 判定时机 | **第2天起**，每天选完餐厅后 |
| 触发概率 | 条件首次满足时掷一次骰，**35%** 概率乱入（每局仅判定一次，不随天数累积） |
| 出现方式 | 替代当日常规对手，弹出专属登场文案 |
| 每局限制 | 击败过一次后不再乱入（`challengerDefeated`） |
| 首日保护 | 第1天不会乱入（给玩家适应期） |
| 区域老板 | 阈值按天数缩放（2天局：连胜2天 / 硬刚2次 / 专业20），保证条件可达 |

#### 击败奖励（非通关，是额外收益）

| 奖励 | 数值 |
|------|------|
| 额外晋升 | **+1 级**（可与当场晋升叠加） |
| 好感 | **+10** |
| 面子 | **+20** |
| 金钱 | **+5000** |

**失败无额外惩罚**：按当天常规结算判定（升职/维持/降级/被优化），不会因"没答好普老板的问题"而直接失败。

#### 与传统 Boss 的对比

| 维度 | 传统 Boss | 本作乱入挑战者 |
|------|----------|--------------|
| 出现时机 | 固定最终日 | 第2天起任意一天，随机 |
| 出现条件 | 必经 | 需玩家表现"扎眼"才触发 |
| 与通关关系 | 必须击败 | 完全无关，纯额外收益 |
| 玩家心态 | 压力、必须准备 | 惊喜、意外之喜 |
| 稀有度 | 100% 遇到 | 有条件 + 35% 概率 |

> 📖 **登场文案、专属考核事件、通关/失败文案** → 见 [角色与对话文案 v1.2.1 §4](./角色与对话文案-酒桌文化v1.2.1.md)

**设计意图**：

- **稀有性**：普通玩家整局可能遇不到普老板，只有特定玩法才能解锁
- **奖励性格**：鼓励玩家"硬刚"而非一味拍马屁，与游戏"吐槽酒桌文化"的调性一致
- **非通关门槛**：击败她是额外奖励，与通关判定完全解耦

## 6. 美术设计

> **2026-10-15 执行提醒**：当前画风为用户图的日系精细手绘、黑灰米白基底加黄紫重点色。下文简笔线稿、Q版比例、均匀粗描边、旧配色表及约210个素材估算属旧版资料，均由 §0.2 与《美术需求表》§0.3/§1.1 覆盖；不得原样复制旧风格生产。资源尺寸采用美术表的全身1024×1536、半身1024×1024、背景1920×1080等分类规格。所有 UI 皮肤无文字独立拆分，实际文本由运行时渲染。

### 6.1 整体定位

| 项目 | 内容 |
|------|------|
| 美术风格 | 卡通讽刺风（黑色幽默插画 + 暖黄主色） |
| 视觉隐喻 | "社畜图鉴"——用夸张变形消解职场压力 |
| 参考坐标 | 《中国式家长》的亲和感 + 《逆转裁判》的夸张表情 + 微信表情包的传播力 |
| 制作原则 | **低保真高表现**——用简单线条 + 夸张表情传递情绪，降低美术成本 |
| 调性红线 | 不美化酒桌文化、不物化人物、不出现真实品牌商标 |

### 6.2 色彩规范

**主色板**

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#F5A623` | 暖黄，全局识别色，用于主菜单/结算页 |
| 深色面板 | `#262A37` | 游戏内背景，承载信息密度 |
| 卡片面板 | `#303646` | 可交互卡片底色 |

| 神秘紫 | `#B464FF` | 氛围值/隐藏要素 |

**语义化色彩规则**（玩家不看文字也能读懂状态）

| 属性 | 色彩 | 变化逻辑 |
|------|------|---------|
| 好感度 | 绿 → 黄 → 红 | 高好感绿，中等黄，低好感红 |
| 清醒度 | 蓝 → 橙 → 红 | 100% 蓝，30% 以下转红并闪烁 |
| 氛围值 | 紫 | 越高紫色越饱和 |
| 尊严值 | 橙 | 越高越亮 |
| 职级 | 金色系 | Lv. 越高金色越亮，Lv.8 加发光特效 |

**色彩心理学应用**

- 暖黄主色 = 回忆感 + 烟火气，避免冷色带来的"职场压抑"
- 深色游戏面板 = 聚焦感，让数值条和对话成为视觉焦点
- 红色**仅用于负面**（被优化/醉酒），建立条件反射式警示

### 7.5 音频技术实现

```lua
-- BGM 播放（循环 + 淡入淡出）
local bgmNode = scene:CreateChild("BGM")
local bgmSource = bgmNode:CreateComponent("SoundSource")
bgmSource.soundType = "Music"
bgmSource.gain = 0.7
local bgmSound = cache:GetResource("Sound", "Audio/BGM/bgm_tier1.ogg")
bgmSource:Play(bgmSound)

-- SFX 播放（一次性）
local sfxNode = scene:CreateChild("SFX")
local sfxSource = sfxNode:CreateComponent("SoundSource")
sfxSource.soundType = "Effect"
sfxSource:Play(cache:GetResource("Sound", "Audio/SFX/sfx_dice_roll.ogg"))
```

**关键要点**：

- BGM 与 SFX 使用不同 `soundType`，便于独立调节音量
- 骰子音效需**顺序播放**（滚动 → 落地 → 结果），使用 `SoundSource:Play()` 配合定时器
- 环境音使用 `loop = true` 的 Sound 资源
- 淡入淡出通过 `Transition` 组件或手动插值 `gain` 实现

### 7.6 音量设置与无障碍

| 设置项 | 默认值 | 范围 |
|--------|--------|------|
| 总音量 | 80% | 0-100% |
| BGM 音量 | 70% | 0-100% |
| 音效音量 | 90% | 0-100% |
| 静音 | 关 | 开关 |

**无障碍考虑**：

- 所有关键音效都有**视觉替代**（如数值飘字、屏幕震动）
- 提供"音效强化"模式，为听力障碍玩家加大视觉反馈
- 不使用音频作为唯一的信息传递渠道

### 8.5 新手引导设计

| 阶段 | 引导方式 | 内容 |
|------|---------|------|
| 首次启动 | 全屏遮罩 + 手指提示 | "点击开始入职" |
| 首次选角色 | 气泡提示 | "角色决定你的起始职级和技能" |
| 首次选酒 | 高亮 + 说明 | "酒越贵面子越高，但不一定最好" |
| 首次摇骰 | 暂停 + 说明 | "骰子决定谁掌握话语权" |
| 首次结算 | 逐项高亮 | "好感度决定升职，清醒度低于0会醉倒" |
| 首次醉酒 | 抖动 + 提示 | "你已经上头了，说话开始不受控制..." |

**引导原则**：

- **非阻塞式**：用气泡提示而非强制弹窗，玩家可跳过
- **情境化**：在玩家首次遇到该机制时才提示，不做一次性灌输
- **可重看**：设置页提供"新手引导回顾"

### 8.6 信息架构与状态可见性

**玩家需要随时知道的信息**（常驻 HUD）：

| 信息 | 位置 | 优先级 |

| 当前职级 | 中上 | 高 |
| 剩余资金 | 右上 | 高 |
| 好感度/清醒度/氛围值 | HUD 下方 | 中 |
| 回合进度 | 骰子旁 | 中 |

**延迟揭示的信息**（制造悬念）：

| 信息 | 揭示时机 | 原因 |
|------|---------|------|

## 10. 技术实现要点

### 10.1 架构建议

**当前 Demo 已实现结构**（`scripts/`）：

```
scripts/
├── main.lua              -- 入口：Start/Stop + 屏幕路由 (SwitchScreen)
├── Data/
│   └── GameData.lua      -- 静态数据层：职级/角色/场景/酒水/事件/结局文案
├── Game/
│   └── GameLogic.lua     -- 状态机 + 全部玩法逻辑（无 UI 依赖）
└── UI/
    └── Screens.lua       -- 全部界面构建（纯展示，调用 GameLogic）
```

**分层原则**：

| 层 | 职责 | 禁止 |
|----|------|------|
| Data | 纯静态数据表，无逻辑 | 不引用 Game/UI |
| Game | 状态 + 规则 + 数值计算 | 不引用 UI |
| UI | 构建控件树 + 触发回调 | 不直接改 State，只调 GameLogic 方法 |
| main | 生命周期 + 屏幕路由 | 不写业务逻辑 |

**扩展规划**（v1.5+ 内容量增长后拆分）：

```
scripts/
├── main.lua
├── Data/
│   ├── GameData.lua      -- 职级/角色/场景/酒水
│   ├── Events.lua        -- 对话事件库（>200条时独立）
│   └── Achievements.lua  -- 称号/成就数据
├── Game/
│   ├── GameLogic.lua     -- 状态机主控
│   ├── DiceSystem.lua    -- 骰子逻辑 + 权重计算
│   ├── ScoreSystem.lua   -- 属性计算 + 结局判定
│   └── SkillSystem.lua   -- 角色技能效果
├── UI/
│   ├── Screens.lua       -- 屏幕路由分发
│   ├── ScreenMenu.lua    -- 主菜单 + 选择类界面
│   ├── ScreenGame.lua    -- 酒局界面
│   └── ScreenResult.lua  -- 结算 + 终局界面
└── Utils/
    ├── SaveManager.lua   -- 存档
    └── Leaderboard.lua   -- 排行榜（云变量）
```

**拆分触发条件**：单文件超过 1000 行时提取独立模块。

### 10.2 关键技术点

- **对话系统**：使用数据驱动的对话树，支持条件分支
- **骰子动画**：NanoVG 或 3D 骰子模型 + 物理模拟
- **UI系统**：使用 urhox-libs/UI 组件库
- **数据存储**：云变量保存排行榜，本地保存解锁进度
- **随机性**：种子随机+权重系统，保证体验公平但不完全重复
