## 1. 项目概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 职场生存战 (Office Survival) |
| 游戏类型 | 模拟经营 / 策略决策 / 黑色幽默 |
| 目标平台 | 移动端（TapTap）、PC |
| 目标受众 | 18-35岁打工人群体，喜爱轻策略+解压游戏 |
| 游戏时长 | 单局 10-15 分钟，可反复挑战不同策略 |
| 开发周期 | 3-5 周 |
| 团队规模 | 1-2 人 |
| 引擎 | UrhoX (TapTap制造) |

### 1.2 一句话描述

**作为游戏公司唯一的项目经理，在老板的疯狂PUA和团队的摆烂之间左右逢源，用30天把游戏怼上线！**

### 1.3 核心卖点

1. **极强共鸣** — 打工人日常的夸张演绎，笑中带泪
2. **决策博弈** — 每个选择都有代价，没有完美方案
3. **黑色幽默** — 讽刺职场PUA文化，解压减负
4. **轻量策略** — 单局10分钟，随时开一把
5. **多结局** — 从被开除到财务自由，看你能走多远

## 2. 游戏世界观

### 2.1 背景故事

你是「梦想互娱」游戏公司新上任的项目经理。

公司只有一款游戏项目——离上线还有30天。老板每天打电话给你布置不可能完成的任务、疯狂PUA、临时改需求。你手下有一个4人小团队，士气低迷、随时准备跑路。预算紧张到连下午茶都买不起。

你的目标：**在30天内把游戏怼上线，同时不被开除、不逼走团队、不破产。**

### 2.2 公司设定

| 信息 | 内容 |
|------|------|
| 公司名 | 梦想互娱 |
| 规模 | 6人（老板+你+4个下属） |
| 项目 | 一款手游（类型随机/玩家可选） |
| 财务 | 濒临破产，预算极度紧张 |
| 文化 | 老板推崇"狼性文化"、"福报论" |

## 3. 核心玩法设计

### 3.1 游戏循环

```
每日开始
    ↓
老板来电（1-3次随机事件）
    ↓
选择：接听 / 挂断 / 静音
    ↓
处理结果 + 布置当日工作
    ↓
分配团队任务（拖拽卡牌到工位）
    ↓
消耗资源（资金/时间/精力）
    ↓
结算当日进度
    ↓
检查数值（项目进度/团队士气/资金/老板好感）
    ↓
下一天 / 触发结局
```

### 3.2 核心系统一：电话决策系统

#### 老板来电机制

每天随机 1-3 通老板来电，每通电话包含一个"指令"：

| 来电类型 | 示例内容 | 频率 |
|---------|---------|------|
| 加班指令 | "今晚全员加班，明天要看到新版本" | 高 |
| 需求变更 | "把主角换成二次元美少女" | 中 |
| 预算削减 | "下个月工资先欠着，画饼嘛" | 中 |
| 无理PUA | "别人家团队3天就搞定了" | 高 |
| 突击检查 | "我5分钟后下去看进度" | 低 |
| 友好时刻 | "做得不错，给你们加个鸡腿"（罕见） | 极低 |

#### 三种应对方式

| 操作 | 效果 | 代价 |
|------|------|------|
| **接听+执行** | 老板好感 +1~3 | 团队士气-2, 可能资金-1, 进度可能偏移 |
| **接听+谈判** | 老板好感 ±0, 有概率说服 | 消耗你的"精力值" |
| **挂断** | 团队士气 +1（觉得你护着他们） | 老板好感 -2~5 |

#### 连锁后果

```
老板好感归零 → 被约谈 → 再次归零 → 被开除（Game Over）
团队士气归零 → 有人提离职 → 不处理 → 集体跑路（Game Over）
资金归零 → 发不出工资 → 团队立刻散伙（Game Over）
```

### 3.3 核心系统二：团队管理系统

#### 团队成员

| 角色 | 职位 | 性格 | 特殊技能 |
|------|------|------|---------|
| 阿强 | 主程序 | 沉默寡言，但技术过硬 | 加班不掉士气（但连续3天会猝死请假） |
| 小美 | 美术 | 敏感易怒，创意极佳 | 灵感爆发：随机产出双倍美术进度 |
| 大伟 | 策划 | 老油条，善于摸鱼 | 话术精通：帮你挡老板电话1次/周 |
| 小新 | 测试 | 新人热情，但容易出错 | 加班热情：主动加班不扣士气（前期） |

#### 每日任务分配

将任务卡牌拖到对应成员的工位上：

| 任务类型 | 产出 | 适合成员 |
|---------|------|---------|
| 写代码 | 程序进度+3 | 阿强（效率×2） |
| 做美术 | 美术进度+3 | 小美（效率×2） |
| 写文档 | 策划进度+3 | 大伟（效率×2） |
| 测试Bug | 质量+2 | 小新（效率×2） |
| 摸鱼 | 士气+2, 进度+0 | 任何人 |
| 加班 | 对应进度+2（额外） | 任何人（士气-1） |
| 团建 | 全队士气+3 | 消耗资金 |

### 3.4 核心系统三：资源管理

#### 四大核心数值

| 数值 | 范围 | 归零后果 | 恢复方式 |
|------|------|---------|---------|
| 项目进度 | 0-100% | 到30天未满100%则项目失败 | 每日工作产出 |
| 团队士气 | 0-100 | 有人离职/集体跑路 | 摸鱼、团建、挂断老板电话 |
| 公司资金 | 0-999K | 发不出工资则散伙 | 初始固定，老板偶尔追加 |
| 老板好感 | 0-100 | 被开除 | 接老板电话、完成指标 |

#### 资金用途

| 消费项 | 花费 | 效果 |
|--------|------|------|
| 正常工资 | 每周自动扣除 | 基本维持运营 |
| 加班费 | 每次加班 | 减少加班士气惩罚 |
| 下午茶 | 小额 | 全队士气+1 |
| 团建活动 | 中额 | 全队士气+5 |
| 外包支援 | 大额 | 进度直接+10% |
| 给老板买礼物 | 大额 | 老板好感+10（但有被发现风险） |

### 3.5 核心系统四：随机事件

除了老板来电外，每天还可能触发随机事件：

| 事件 | 效果 | 应对选择 |
|------|------|---------|
| 程序员电脑蓝屏 | 当日程序进度归零 | 花钱换新电脑 / 让他用备用机 |
| 竞品公司挖人 | 某成员忠诚度-20 | 加薪挽留 / 放他走 / 画饼 |
| 甲方临时改需求 | 回退3天进度 | 执行 / 拒绝（老板好感-5） |
| 团队内讧 | 两人士气各-10 | 调解 / 无视 / 罚款 |
| 发现严重Bug | 质量-20 | 加班修复 / 带Bug上线 |
| 老板出差（福利！） | 3天无来电 | 自由安排时间 |
| 投资人来访 | 如果项目进度>50%，资金+100K | — |
| 主程猝死（开玩笑） | 阿强请假3天 | 等待 / 花钱请临时工 |

## 4. 结局设计

### 4.1 结局列表

| 结局 | 条件 | 描述 | 评价 |
|------|------|------|------|
| **S. 财务自由** | 项目上线+质量>80+获得投资 | 游戏大卖，你成为合伙人 | ★★★★★ |
| **A. 完美上线** | 30天内进度100%+质量>60 | 游戏正常上线，团队庆功 | ★★★★ |
| **B. 勉强上线** | 进度100%但质量<60 | 上线后差评如潮，但至少没失业 | ★★★ |
| **C. 跳槽成功** | 老板好感<20但士气>80 | 带着团队集体跳槽到更好的公司 | ★★★ |
| **D. 被开除** | 老板好感归零 | 被扫地出门，但获得自由 | ★★ |
| **E. 团队解散** | 士气归零 | 所有人跑路，项目流产 | ★ |
| **F. 公司破产** | 资金归零 | 发不出工资，关门大吉 | ★ |
| **隐藏. 反杀** | 收集3次老板违规证据 | 举报老板，你成为新老板 | ★★★★★ |

### 4.2 结局CG

每个结局配有一张像素/手绘风格的结局插图 + 一段总结文字。

## 5. 数值设计

### 5.1 基础数值平衡

| 参数 | 数值 | 说明 |
|------|------|------|
| 游戏总天数 | 30天 | 一局游戏长度 |
| 每天工作进度上限 | 约5-8% | 需要合理分配才能30天内完成 |
| 初始资金 | 300K | 仅够发4周工资+少量额外支出 |
| 初始士气 | 60/100 | 不高不低，需要维护 |
| 初始老板好感 | 50/100 | 中等，有容错空间 |
| 老板来电频率 | 1-3次/天 | 随天数增加而增加 |

### 5.2 难度曲线

```
第1-7天（新手期）：
  老板来电 1次/天，内容温和
  随机事件较少
  让玩家熟悉系统

第8-15天（压力期）：
  老板来电 2次/天，开始PUA
  随机事件增多
  需要开始做取舍

第16-25天（高压期）：
  老板来电 2-3次/天，变本加厉
  高概率负面事件
  数值开始吃紧

第26-30天（冲刺期）：
  老板每天打3次电话催进度
  团队濒临崩溃
  最终决战时刻
```

## 9. 交互设计

### 9.1 核心交互流程

```
[游戏开始]
    ↓
[每日晨会]：显示当日概况、昨日数据变化
    ↓
[老板来电]：弹出电话界面，限时选择（5秒不选=自动接听）
    ↓
[任务分配]：拖拽任务卡到成员工位
    ↓
[确认执行]：点击"开工"按钮，播放工作动画（可快进）
    ↓
[下班结算]：显示当日产出、数值变化
    ↓
[随机事件]（50%概率触发）：弹出事件，做出选择
    ↓
[进入下一天] / [触发结局]
```

### 9.2 电话交互细节

```
来电动画：
1. 屏幕震动 + 铃声响起
2. 显示"老板来电"（带秃头头像）
3. 下方三个按钮逐渐出现
4. 5秒倒计时（不选则自动接听）

挂断反馈：
1. "嘟——"音效
2. 屏幕弹出老板愤怒表情包
3. "老板好感 -3" 飘字
4. 团队成员冒出爱心（士气+1）
```

## 10. 运营设计

### 10.1 版本规划

| 版本 | 内容 | 目标 |
|------|------|------|
| v0.1 | 核心循环（来电+分配+结算）| 验证手感 |
| v0.5 | 完整30天+4个结局 | 流程测试 |
| v1.0 | 8个结局+随机事件+美术 | 正式发布 |
| v1.5 | 每周挑战模式+排行榜 | 增加重玩性 |
| v2.0 | 新公司/新团队DLC | 持续内容 |

### 10.2 重玩性设计

| 机制 | 说明 |
|------|------|
| 多结局 | 8种结局鼓励多次尝试 |
| 随机事件 | 每局事件组合不同 |
| 策略多样性 | 强硬路线 vs 和谐路线 vs 摸鱼路线 |
| 成就系统 | "连续挂断老板5次" "全员满士气通关" 等 |
| 排行榜 | 最快通关/最高质量/最省钱 |

### 10.3 盈利模式

- 免费游玩（基础内容完全免费）
- 激励广告（可选看广告获得额外资金/恢复士气）
- 付费DLC（新场景：广告公司/外包团队/独立工作室）

| 风险 | 等级 | 应对 |
