## 1. 项目概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 挂断吧！老板！ |
| 游戏类型 | 模拟经营 / 放置点击 / 黑色幽默 |
| 目标平台 | 移动端（TapTap）、PC |
| 开发者 | SunEven的工作室 |
| 目标受众 | 18-35岁职场人群，碎片化休闲玩家 |
| 游戏时长 | 单局 5-10 分钟，长期养成 |
| 引擎 | UrhoX (TapTap制造) |
| 开发者寄语 | "快乐工作不加班！！！" |

### 1.2 一句话描述

**作为游戏公司的项目经理，在老板的疯狂PUA中指挥团队、管理资金、推进项目上线——成为企业中的"赛博财神爷"！**

### 1.3 核心体验关键词

- 💰 赛博财神爷（点击赚钱的爽快感）
- 📞 挂断老板（职场解压的情绪宣泄）
- 🎯 项目推进（策略经营的成就感）
- 😂 黑色幽默（职场PUA的讽刺快乐）

## 2. 核心玩法逆向分析

### 2.1 玩法架构图

根据公开信息，游戏由**三大核心系统**组成：

```
┌───────────────────────────────────────────┐
│              《挂断吧！老板！》              │
├───────────────┬───────────────┬───────────┤
│  💰 赛博财神爷 │  📞 老板PUA应对  │ 👥 团队管理 │
│  （资金获取）  │  （事件决策）    │ （资源分配）│
├───────────────┴───────────────┴───────────┤
│              📊 项目进度推进                 │
│          （最终目标：游戏上线）              │
└───────────────────────────────────────────┘
```

### 2.2 三大核心系统

#### 系统一：赛博财神爷（核心经济循环）

**玩法**：点击屏幕中的财神爷图标获取资金

```
点击财神爷
    ↓
随机掉落（金元宝/红包/金条/铜板）
    ↓
积累资金
    ↓
用于：发工资 / 团建 / 外包 / 应急 / 升级
    ↓
资金不足 → 需要更多点击 / 解锁被动收入
```

| 掉落物 | 价值 | 概率 | 特效 |
|--------|------|------|------|
| 铜板 | 1金 | 50% | 轻微弹跳 |
| 红包 | 5金 | 30% | 红色烟花 |
| 金元宝 | 20金 | 15% | 金光闪闪 |
| 金条 | 100金 | 4% | 全屏金雨 |
| 彩蛋：程序员的肝 | 500金 | 1% | 特殊动画 |

**升级系统**：

| 升级项 | 效果 | 花费 | 最高等级 |
|--------|------|------|---------|
| 点击收益 | 每次点击基础收入+1 | 递增 | 50 |
| 自动收入 | 每秒自动获取X金 | 递增 | 30 |
| 暴击概率 | 点击有概率双倍/三倍 | 递增 | 20 |
| 稀有掉落 | 提高金条出现概率 | 递增 | 10 |
| 连击加成 | 连续快速点击加成倍率 | 递增 | 15 |

#### 系统二：老板来电与PUA应对

**触发机制**：每隔一定时间（或项目进度节点），老板来电

```
┌──────────────────────────────┐

│                              │
│  [老板头像：秃顶+西装+愤怒]  │

│  "明天必须上线！我不管你      │
│   们怎么做到，做不到都滚！"   │
│                              │
│  ┌────┐  ┌────┐  ┌────┐    │
│  │接听│  │敷衍│  │挂断│    │
│  └────┘  └────┘  └────┘    │
└──────────────────────────────┘
```

**来电事件库**（按类别分类）：

| 类别 | 事件内容 | 频率权重 |
|------|---------|---------|
| **加班PUA** | "别人公司996是福报，我们只是995，你们还有什么不满足的？" | 高 |
| **画饼** | "这个项目做完了，年终奖翻三倍，我说到做到！" | 高 |

**三种应对方式及效果**：

| 应对 | 老板满意度 | 团队士气 | 资金影响 | 项目影响 | 特殊效果 |
|------|-----------|---------|---------|---------|---------|
| **接听执行** | +3~5 | -2~5 | 可能-资金 | 可能偏移方向 | 解锁"卷王"称号 |
| **敷衍应付** | +0~1 | ±0 | 无 | 无 | 消耗1点精力值 |
| **挂断** | -3~8 | +1~3 | 无 | 无 | 触发挂断动画+解压音效 |

**挂断的爽快感设计**：

    ↓

**连续挂断彩蛋**：

| 连续挂断次数 | 触发效果 |

## 3. 数值系统设计

### 3.1 核心数值面板

| 数值 | 初始值 | 范围 | 归零后果 | 说明 |
|------|--------|------|---------|------|
| 项目进度 | 0% | 0-100% | 限时内未达100%=项目流产 | 核心目标 |
| 团队士气 | 70 | 0-100 | 成员离职 | 过低时效率骤降 |
| 公司资金 | 500金 | 0-∞ | 破产结束 | 财神爷系统获取 |
| 老板满意度 | 50 | 0-100 | 被开除 | 接电话/完成指标提升 |
| 项目质量 | 50 | 0-100 | 上线后差评如潮 | 影响最终评价 |
| 精力值 | 5/5 | 0-5 | 无法敷衍（只能接或挂） | 每天恢复1点 |

### 3.2 数值联动关系

```
老板满意度 ↓ → 来电频率 ↑（越不满意越爱打电话）
团队士气 ↓ → 工作效率 ↓（士气<30时效率减半）
资金 ↓ → 无法支付加班费/团建（士气恢复受限）
项目进度 ↑ → 老板施压 ↑（越接近上线越疯狂）
质量 ↓ → 上线后结局评分 ↓
```

### 3.3 经济模型

| 收入来源 | 数值 | 频率 |
|---------|------|------|
| 财神爷点击 | 1-100金/次 | 手动 |
| 自动收入 | X金/秒 | 持续 |
| 阶段奖金 | 200金 | 完成里程碑 |
| 老板打赏 | 50-100金 | 满意度>80时随机 |

| 支出项 | 数值 | 频率 |
|--------|------|------|
| 基本工资 | 100金 | 每3天 |
| 加班费 | 30金 | 每次加班 |
| 团建费 | 80金 | 每次团建 |
| 外包费 | 200金 | 按需 |
| 设备维修 | 50金 | 随机事件 |

## 4. 游戏流程与节奏

### 4.1 一局游戏结构

```
[Day 1-5：新手教程期]
  - 学会点击财神爷
  - 接到第一通老板电话（教学：三种选择）
  - 学会分配任务
  - 节奏轻松

[Day 6-15：稳步发展期]
  - 老板来电频率增加（每天1-2通）
  - 需要平衡资金和士气
  - 第一次里程碑（原型完成）
  - 开始遇到随机事件

[Day 16-25：高压冲刺期]
  - 老板来电频率高（每天2-3通）
  - PUA强度升级
  - 资金紧张，需精打细算
  - 团队成员可能提出离职
  - 需要做出艰难取舍

[Day 26-30：最终决战期]
  - 老板几乎每小时打一次电话
  - "最后冲刺！不上线就全完了！"
  - 极限资源管理
  - 迎来最终结局
```

### 4.2 每日流程

```
┌─────────────────────────────────────────┐
│  🌅 每日开始                             │
│  └→ 显示：日期、资金、士气、进度概况      │
├─────────────────────────────────────────┤
│  📞 老板来电（0-3次，随机时间触发）       │
│  └→ 选择：接听/敷衍/挂断                │
├─────────────────────────────────────────┤
│  💰 财神爷点击（全天可用）                │
│  └→ 疯狂点击积攒资金                    │
├─────────────────────────────────────────┤
│  👥 团队任务分配（每日1次）               │
│  └→ 给4位成员安排当天工作                │
├─────────────────────────────────────────┤
│  🎲 随机事件（50%概率触发）               │
│  └→ 处理突发状况                         │
├─────────────────────────────────────────┤
│  🌙 每日结算                             │
│  └→ 显示当日成果、数值变化               │
└─────────────────────────────────────────┘
```

## 5. 随机事件系统

### 5.1 事件分类与示例

#### 正面事件（20%概率）

| 事件 | 效果 | 选择 |
|------|------|------|
| 投资人来视察 | 如果进度>50%，资金+300金 | 自动触发 |
| 竞品延期了 | 老板满意度+10（压力减轻） | 自动触发 |
| 程序员灵光一现 | 进度+5%，质量+5 | 自动触发 |
| 公司年会抽奖 | 获得随机奖品（加成buff） | 选择奖品 |

#### 负面事件（50%概率）

| 事件 | 效果 | 选择 |
|------|------|------|
| 服务器宕机 | 当日进度归零 | 花钱修/等明天 |
| 核心程序员收到Offer | 老K忠诚度-30 | 加薪/画饼/放人 |
| 需求文档丢失 | 进度-10% | 加班补/从头来 |
| 办公室空调坏了 | 全员士气-5 | 花钱修/忍着 |
| 老板带亲戚来实习 | 效率-20%持续3天 | 接受/拒绝(好感-10) |
| 竞品上线了 | 老板满意度-10（施压） | 无 |
| 测试发现严重Bug | 质量-15 | 花时间修/忽略 |

#### 抉择事件（30%概率）

| 事件 | 选项A | 选项B | 选项C |
|------|-------|-------|-------|
| 员工匿名举报加班 | 调查(耗时) | 无视(士气-5) | 改善(资金-100) |
| 发现可复用的开源代码 | 使用(进度+10%,质量风险) | 不用(安全) | — |
| 客户要加紧急需求 | 接(进度-5%,资金+150) | 拒(无影响) | — |
| 有人在摸鱼直播 | 开除(少一人) | 警告(士气-3) | 假装没看到 |

## 6. 结局系统

### 6.1 结局一览

| 结局 | 评级 | 条件 | 描述 |

| **SSS. 上市敲钟** | 传说 | 进度100%+质量>90+资金>1000 | 游戏爆火，公司上市，你成了CTO |

## 13. 核心设计理念总结

### 13.1 为什么这个游戏能成功

```
情绪价值 × 碎片时间 × 策略深度 = 上瘾循环

1. 情绪价值：
   - 挂断老板 = 现实中不敢做的事（替代满足）
   - 财神爷掉钱 = 即时正反馈（多巴胺）
   - PUA名言图鉴 = 笑中带泪的共鸣（社交传播）

2. 碎片时间：
   - 5分钟能完成一天流程
   - 随时可以摸鱼点财神爷
   - 离线也有收益

3. 策略深度：
   - 接/挂电话的长期后果
   - 资源分配的取舍
   - 多结局的重玩探索
```

### 13.2 一句话设计哲学

> **"让每一次挂断都成为打工人的精神胜利，让每一次点击都离财务自由更近一步。"**
