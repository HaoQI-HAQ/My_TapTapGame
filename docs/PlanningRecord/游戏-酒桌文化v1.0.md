# 《酒桌文化》游戏策划案

> **一句话概述**：一款以中国职场酒桌为背景的幽默策略对话游戏，玩家通过摇骰子、选对话、点菜、选酒，在荒诞的职场应酬中决定自己的命运走向。

---

## 1. 游戏概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 《酒桌文化》 |
| 游戏类型 | 策略对话 / 骰子决策 / 多分支剧情 |
| 目标平台 | 移动端（竖屏/横屏均可，推荐横屏） |
| 美术风格 | 卡通讽刺风（黑色幽默插画 + 黄色/暖色调 UI） |
| 核心受众 | 18-35岁职场人群，社畜共鸣向 |
| 游戏时长 | 单局 5-8 分钟，高重玩性 |
| 调性定位 | **幽默解压、荒诞讽刺、会心一笑**（绝不贩卖焦虑） |

### 1.2 设计理念

- **笑着活下去**：用夸张荒诞的幽默消解职场压力，让玩家在游戏里"社死"比在现实中"社死"开心一万倍
- **每局不一样**：事件组合随机 + 多分支选择 = 极高重玩性
- **骰子是命运**：摇骰子不是纯随机，而是"命运加成"——你的选择影响骰子权重
- **社畜百态**：每个角色、每句台词都是职场人的"DNA动了"时刻

## 2. 核心玩法

### 2.1 游戏流程

```
┌─────────────────────────────────────────────────┐
│  选择职场环境 → 选择扮演角色 → 选择饭局场景     │
│       ↓                                         │
│  选酒（类型→品牌）→ 点菜 → 进入酒桌对话        │
│       ↓                                         │
│  ┌─────────────────────────────┐                │
│  │ 循环回合（6-10回合/局）：    │                │
│  │  双方摇骰子 → 触发事件      │                │
│  │  → 对话选择（3-4选项）      │                │
│  │  → 结算本回合影响           │                │
│  └─────────────────────────────┘                │
│       ↓                                         │
│  最终结算 → 三种结局之一 → 排行榜 → 重开        │
└─────────────────────────────────────────────────┘
```

### 2.2 骰子机制

每回合双方各摇一次骰子（玩家 + 对面的人）：

| 骰子组合 | 触发效果 |
|----------|----------|
| 玩家 > 对方 | 玩家掌握话语权，可以主动出击 |
| 玩家 < 对方 | 被动应对，需要圆场/接话 |
| 双方相同 | 触发"干杯事件"，强制饮酒并进入特殊对话 |
| 出现豹子（如66） | 触发稀有剧情事件（如老板突然打电话来） |

**隐藏机制**：玩家之前的选择会微调骰子概率（如选了茅台，"面子值"高，骰子略有加成）

### 2.3 对话选择系统

每次对话提供 3-4 个选项，风格分类：

| 风格类型 | 示例 | 效果倾向 |
|----------|------|----------|
| 🐴 职场马屁 | "张总这格局，我学一辈子都学不来" | +好感度，-尊严值 |
| 🔥 阴阳怪气 | "可不嘛，毕竟您工资是我十倍" | -好感度，+尊严值，可能触发隐藏线 |
| 🧠 行业黑话 | "这个我们要拉齐一下颗粒度" | +专业度，对方可能懵逼 |
| 🍺 酒桌套路 | "感情深一口闷，感情浅舔一舔" | +氛围值，-清醒度 |
| 😶 沉默摸鱼 | "嗯嗯，对对对，您说得对" | 中性，保命但无功无过 |
| 💀 整活发疯 | "不好意思，我要去厕所哭一会儿" | 随机效果，可能大加分或直接结束 |

### 2.4 数值系统

#### 核心属性（隐藏，结算时揭晓）

| 属性 | 说明 | 影响 |
|------|------|------|
| 好感度 | 对方对你的印象 | 直接影响结局走向 |
| 尊严值 | 你还剩多少自我 | 影响结局称号和隐藏剧情 |
| 清醒度 | 你还能正常说话吗 | 低于阈值触发"醉酒模式"（选项变乱） |
| 氛围值 | 饭局整体气氛 | 影响事件触发概率 |
| 面子值 | 场面功夫做得如何 | 受选酒、选餐厅影响 |

#### 金钱系统

- 初始资金根据角色不同（打工人 ¥2000 vs 区域老板 ¥50000）
- 选餐厅、选酒、点菜都要花钱
- **钱花得多不一定好**（可能被认为"不会过日子"或"太装"）
- **钱花得少也不一定差**（可能被认为"务实"或"抠门"）
- 结算时剩余金额影响评分

选项：
A. "对，我们需要建立一个闭环的方法论" → 专业度+5

C. "我觉得可以先对齐一下OKR" → 专业度+3，触发黑话连环

**职场拍马屁类**（国企/金融专属）：

选项：
A. "您太辛苦了，要注意身体啊" → 好感+3（标准答案）

## 4. 结局系统

### 4.1 三大结局走向

| 结局 | 触发条件 | 结局文字 |
|------|----------|----------|
| ⬆️ 升职加薪 | 好感高 + 面子足 + 没醉到失态 | "恭喜你，下周一去新部门报到" |
| ➡️ 维持现状 | 各项中等，没出大错也没亮点 | "这顿饭...好像白吃了" |
| 💀 被优化 | 好感低 / 踩到雷区 / 醉到失控 | "明天来HR办公室一趟" |

### 4.2 特殊结局（隐藏）

| 结局 | 触发条件 | 结局文字 |

## 9. 技术实现要点

### 9.1 架构建议

```
scripts/
├── main.lua              -- 入口，场景管理
├── Game/
│   ├── GameManager.lua   -- 游戏状态机（选择→游戏→结算）
│   ├── DiceSystem.lua    -- 骰子逻辑+权重计算
│   ├── DialogSystem.lua  -- 对话树+分支管理
│   └── ScoreSystem.lua   -- 属性计算+结局判定
├── Data/
│   ├── Events.lua        -- 事件数据库
│   ├── Dialogues.lua     -- 对话数据库
│   ├── Items.lua         -- 酒水/菜品数据
│   └── Characters.lua    -- 角色数据
├── UI/
│   ├── MainMenu.lua      -- 主菜单
│   ├── GameHUD.lua       -- 游戏内HUD
│   ├── DialogPanel.lua   -- 对话选择面板
│   ├── DiceAnimation.lua -- 骰子动画
│   └── ResultScreen.lua  -- 结算界面
└── Utils/
    └── SaveManager.lua   -- 存档/排行榜
```

### 9.2 关键技术点

- **对话系统**：使用数据驱动的对话树，支持条件分支
- **骰子动画**：NanoVG 或 3D 骰子模型 + 物理模拟
- **UI系统**：使用 urhox-libs/UI 组件库
- **数据存储**：云变量保存排行榜，本地保存解锁进度
- **随机性**：种子随机+权重系统，保证体验公平但不完全重复
