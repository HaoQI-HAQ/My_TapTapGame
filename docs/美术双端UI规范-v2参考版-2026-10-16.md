## 2. 三端尺寸与安全区

像素值均指设计画布，不等于每台设备的物理像素。下列逻辑倍率是设计换算，不是设备 DPR 强制值。

| 端 | 设计画布 | 设计逻辑尺寸 | 推荐安全边距 L/T/R/B（设计 px） | 推荐安全内容框 |
|---|---|---|---|---|
| PC | 1920×1080 | 1920×1080，按设计比例适配 | 48/36/48/36 | x=48…1872，y=36…1044 |
| 手机主竖屏 | 1080×1920 | 360×640 @3× | 60/96/60/96 | x=60…1020，y=96…1824 |
| 手机补充横屏 | 1920×1080 | 800×450 @2.4× | 150/60/150/60 | x=150…1770，y=60…1020 |

**逐边取 max：** 将系统刘海、圆角、挖孔及底部手势 safe inset 换算到同一坐标系，再与推荐边距逐边取较大值。以上不是全设备安全保证；返回、暂停、正文、按钮都必须留在实际安全内容框内。

**当前项目仍是 landscape，未修改配置。** 手机竖屏是美术主提案，不代表工程已经切换竖屏或实现方向自适应。

### 适配与阅读

- 背景使用等比 `cover`，允许裁去不关键环境；人物、图标、Logo 等比 `contain`。长屏增加环境留白、调整人物位置和 UI 排列，**禁止整屏非等比拉伸**。
- 文字由程序独立叠加；长文本换行、容器增高或内容滚动，不为了塞入原图而无限缩字。结算长内容可滚动，主 CTA 保留在安全区；此处只规定视觉，不实现功能。
- PC 在窄窗口下缩放／重排后仍需复核可读性。手机横屏只有 450 逻辑高度，优先压缩装饰与人物区域，不能挤压回答的触摸区域。

## 3. 字号、间距与触摸目标

| 项目 | PC（设计 px） | 手机竖屏（设计 px / dp） | 手机横屏（逻辑 dp / 设计 px） |
|---|---|---|---|
| 对话／答案正文 | 26–32 | 48–54 / 16–18 | 16–20 / 38.4–48 |
| 重要状态文字 | 24–28 | 42–48 / 14–16 | 16–18 / 38.4–43.2 |
| 页面／结算标题 | 64–96 | 72–96 / 24–32 | 24–32 / 57.6–76.8 |
| 主 CTA 高度 | 建议 112–144 | **至少 144 / 48** | **至少 48 / 115.2**，整像素导出取 ≥116 |
| 答案项高度 | 建议 96–112 | **至少 144 / 48**，长文本继续增高 | **至少 48 / 115.2**，取 ≥116 |
| 相邻答案间距 | 建议 16–24 | 建议 18–24 / 6–8 | 建议 8 / 19.2，取约20 |

- 手机所有独立操作触摸目标至少 **48×48 dp**（竖屏144×144 px；横屏向上取整至少116×116 px）；小图标可以小于目标，但外层命中框不能小，也不能互相覆盖。
- **GPT 竖屏草稿中约130 px的答案高度不合格**：130/3≈43.3 dp，不可称为48 dp；准确版本必须以 ≥144 px 重新排版。
- 正文与界面字使用工程已存在的 **NotoSansSC（Regular／Bold／Black）**；墨字 Logo 是独立固定标题图，不将动态文字烘进按钮／面板。文字框、字重和长文本需准确合成与设备预览确认；本轮不导出或替换字体。
- 选中态同时用描边／勾选图标／文本标识表达，不仅换色；禁用态降低亮度但正文仍可辨识。这里只整理已有视觉状态，不新增选择规则或结算行为。

## 4. 页面布局与拆分

| 页面 | PC | 手机竖屏 | 手机横屏 |
|---|---|---|---|
| 主菜单 | 标题／操作在左，人物／环境在右 | 标题上、人物中、主 CTA 下；次操作并列或重排 | 保留左右构图，缩减装饰；操作置实际安全区 |

建议合成顺序（是交付分组，不是代码变更）：`background → characters → table_foreground/props → hud → dialogue_panel/text → answers/buttons/text → feedback/settlement → overlays`。桌前景与人物遮挡需按构图局部调整。

准确位置、文字框、组件大小、锚点与 z 顺序由 `05_spec/layout_spec.json` 和另交合成图共同确认；**不能从 GPT 平面图反推为已实现的精确布局**。文字／组件框位于推荐设计安全框内，也不代表已经适配每台设备的实际safe inset或命中区域。

## 8. 第二阶段：运行 UI 接入（2026-10-16）

- 运行纹理位于 `assets/image/Art/UI/JiuzhuoV2/`，最终包含 **40 张 PNG，约 11.72 MiB** 及配套引擎 meta；只派生独立 PNG，不在代码中引用整屏图、ORA 或 ZIP。制作原稿及候选不覆盖，`References` 继续排除构建。
- 按钮从源图裁为 `[24,24,1000,296]` 后等比缩为 244×68；运行切线顺序 **T/R/B/L = 12/17/16/17**。对话面板为244×116、切线15/19/15/19；结算面板约325×302、切线14/25/14/25。切线均为运行图像像素，不能拿回原图使用。
