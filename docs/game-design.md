# 游戏策划文档

## 第一部分：《五盏酩酊》逆向玩法分析

### 1.1 已知信息汇总

| 项目 | 内容 |
|------|------|
| 游戏名称 | 五盏酩酊 |
| 类型 | 冒险游戏 |
| 背景设定 | "手机突然被黑，界面上怎么突然多了一款叫「口袋酒鬼」的app..." |
| 开发者 | 肉沫的工作室 |
| 开发周期 | 48小时（TapTap聚光灯2026广州场） |
| 平台 | 安卓 / iOS / PC |

### 1.2 名称解读

- "五盏" — 五杯酒，暗示游戏可能有5个关卡/章节/阶段
- "酩酊" — 醉酒状态，暗示核心机制与意识模糊、感知扭曲相关
- 合在一起："喝了五杯就醉了" — 递进式的状态变化

### 1.3 核心设定逆向分析

**"手机被黑 + 多了一个 app"** 这个设定指向一种经典的恐怖/悬疑叙事模式：

#### 设计模式：虚拟手机模拟器（Faux OS）

| 类似作品 | 核心玩法 |
|---------|---------|
| 《Simulacra》 | 探索陌生人手机中的信息，拼凑失踪真相 |
| 《Sara Is Missing》 | 通过手机界面解谜，揭开恐怖事件 |
| 《A Normal Lost Phone》 | 翻阅手机内容，了解机主故事 |
| 《Replica》 | 监控他人手机，做出道德选择 |

#### 推测的核心玩法循环

```
玩家手机"被黑"（元叙事开场）
    ↓
发现「口袋酒鬼」app（游戏中的游戏）
    ↓
每次使用 app = "喝一盏"（推进一个章节）
    ↓
随着"醉酒程度"加深，界面/画面/逻辑逐渐扭曲
    ↓
第五盏 = 完全酩酊 = 真相揭露 / 结局
```

### 1.4 推测的机制设计

#### A. 递进式感知扭曲
- 第1盏：界面正常，轻微异常（某条消息内容诡异）
- 第2盏：文字开始模糊/颠倒，出现幻觉元素
- 第3盏：时间线错乱，之前看到的信息发生变化
- 第4盏：界面大面积扭曲，真假难辨
- 第5盏：真相大白或彻底迷失（多结局）

#### B. 碎片化叙事
- 通过手机中的聊天记录、照片、备忘录等拼凑故事
- 不同"醉酒阶段"能看到不同的隐藏内容
- 回看之前的内容会发现细节变化

#### C. 48小时开发限制下的精简设计
- 大概率是纯文字/图片交互（开发周期短）
- 可能使用分支对话树驱动剧情
- UI 模拟手机界面风格

## 第二部分：类似游戏设计方案

### 2.1 游戏概念

| 项目 | 内容 |
|------|------|
| **暂定名称** | 《深夜来电》(Midnight Call) |
| **类型** | 互动叙事 / 心理悬疑 |
| **核心创意** | 深夜收到陌生来电，手机开始出现异常，通过探索手机中的线索揭开真相 |
| **目标平台** | 移动端（TapTap） |
| **预计体量** | 15-30分钟流程 |

### 2.2 故事大纲

> 凌晨3点，你被一通陌生电话吵醒。接通后只有沉默。
> 挂断后，你发现手机里多了一个从未安装过的 app：「回声」。
> 打开它，里面是一段段录音、照片、和聊天记录——
> 但这些记忆...好像是你自己的。
> 你已经忘了的那些。

### 2.3 核心机制

#### 机制一：回声系统（章节推进）

每次打开「回声」app，会解锁一段新的记忆碎片：

| 章节 | 主题 | 手机异常表现 |
|------|------|-------------|
| 回声 1 | 一通普通的电话 | 屏幕偶尔闪烁 |
| 回声 2 | 被遗忘的约定 | 通知栏出现不存在的消息 |
| 回声 3 | 那天晚上发生了什么 | 时间显示错乱，照片自动切换 |
| 回声 4 | 真相的碎片 | 界面大面积故障，文字重叠 |
| 回声 5 | 最终选择 | 根据之前的选择进入不同结局 |

#### 机制二：手机模拟界面

模拟真实手机操作：
- 主屏幕（app 图标）
- 短信/聊天记录
- 相册（照片作为线索）
- 通话记录
- 备忘录
- 「回声」app（核心入口）

#### 机制三：选择与后果

- 关键节点提供 2-3 个选择
- 选择影响后续能看到的线索
- 最终决定结局走向（3个结局）

#### 机制四：环境干扰（沉浸感）

随着章节推进，手机界面逐渐"失控"：
- 屏幕抖动/闪烁
- 文字扭曲或变色
- 突然弹出诡异通知
- 背景音变化（从安静到低频嗡鸣）

### 2.4 技术实现方案（UrhoX）

```
scripts/
├── main.lua              -- 主入口，场景管理
├── PhoneOS.lua           -- 手机模拟系统（主屏幕、app切换）
├── Apps/
│   ├── EchoApp.lua       -- 「回声」核心app逻辑
│   ├── MessagesApp.lua   -- 短信/聊天界面
│   ├── PhotosApp.lua     -- 相册界面
│   ├── CallLogApp.lua    -- 通话记录
│   └── NotesApp.lua      -- 备忘录
├── Story/
│   ├── StoryManager.lua  -- 剧情管理器（章节、分支）
│   ├── DialogueData.lua  -- 对话/文本数据
│   └── ChoiceSystem.lua  -- 选择系统
├── Effects/
│   └── GlitchEffect.lua  -- 故障效果（屏幕抖动、文字扭曲）
└── Data/
    └── story.json        -- 剧情数据配置
```

### 2.5 UI 设计思路

使用 `urhox-libs/UI` 构建手机模拟界面：

- **主屏幕**：网格布局的 app 图标 + 顶部状态栏（时间、电量、信号）
- **聊天界面**：类似微信的气泡对话布局
- **相册**：网格缩略图 + 点击放大查看
- **回声 app**：暗色调，波形动画 + 文字逐字显示

### 2.6 差异化设计（相比《五盏酩酊》）

| 维度 | 五盏酩酊（推测） | 深夜来电（我们的方案） |
|------|-----------------|---------------------|
| 主题 | 醉酒/酒文化 | 遗忘的记忆/心理悬疑 |
| 叙事载体 | 「口袋酒鬼」app | 「回声」app + 完整手机模拟 |
| 扭曲方式 | 醉酒视觉效果 | 数字故障(Glitch)美学 |
| 情感基调 | 可能偏轻松诡异 | 悬疑+温情（多结局有温暖向） |
| 交互深度 | 48h限制，可能较简 | 多app探索，信息交叉验证 |

### 2.7 开发路线（按模块）

**阶段一：核心框架**
- 手机主屏幕 UI
- App 切换系统
- 基础文本显示

**阶段二：叙事系统**
- 对话/文本数据结构
- 分支选择逻辑
- 章节解锁机制

**阶段三：内容填充**
- 5个章节的完整剧情文本
- 聊天记录、照片、备忘录内容
- 3个结局

**阶段四：沉浸感打磨**
- 屏幕故障特效
- 音效/背景音乐
- 通知弹出系统
- 时间变化效果

### 2.8 结局设计

| 结局 | 条件 | 内容 |
|------|------|------|
| A. 释然 | 选择面对真相 + 选择原谅 | 接受过去，放下执念，手机恢复正常 |
| B. 遗忘 | 选择逃避 / 删除回声app | 记忆再次被封印，但隐约的不安永远存在 |
| C. 真相 | 收集所有隐藏线索 | 发现"回声"app的真正来源，揭开更深层的秘密 |
