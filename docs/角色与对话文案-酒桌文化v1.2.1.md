## 1. 角色设定

### 1.1 可玩角色（9 个）

开局选择角色，决定**起始职级**与**贯穿全程的特殊能力**。资金由职级决定，角色不影响资金。

| # | 角色 | ID | 起始职级 | 特殊能力 | 描述 | 难度 |
|---|------|-----|---------|---------|------|------|
| 1 | 🆕 实习生 | `intern` | Lv.1 | 萌新光环：每场酒局第一次失误不扣好感 | 什么都不懂但什么都想学 | ★☆☆☆☆ |
| 2 | 🐴 打工牛马 | `worker` | Lv.2 | 已读不回：每场可跳过一次强制对话 | 社畜本畜，卑微但有梗 | ★★☆☆☆ |
| 3 | 🎨 设计师 | `designer` | Lv.3 | 五彩斑斓黑：对话中可解锁隐藏创意选项 | 需求听不懂但画得出来 | ★★★☆☆ |
| 4 | 🔧 程序员 | `dev` | Lv.3 | Debug：清醒度下降速度减半 | 高薪但社恐，喝多了可能写代码 | ★★★☆☆ |
| 5 | 🎤 销售冠军 | `sales` | Lv.3 | 话术王：好感度增减幅度 ×1.5 | 能把梳子卖给和尚 | ★★★☆☆ |
| 6 | 📊 HR | `hr` | Lv.3 | 背调：每场可查看对方一个隐藏属性 | 笑里藏刀，信息就是武器 | ★★★☆☆ |
| 7 | 📋 产品经理 | `pm` | Lv.4 | 需求变更：每场可推翻一次已选选项重选 | 永远在改需求 | ★★★★☆ |
| 8 | 👴 老油条 | `veteran` | Lv.5 | 太极推手：每场可将一个负面效果转嫁 | 在公司活了二十年的终极形态 | ★★★★★ |
| 9 | 👔 区域老板 | `boss` | Lv.7 | 我请客：可强制买单提升全场面子值 +20 | 🔥 Hard Mode：仅 2 天 | ★★★★★★ |

**设计意图**

- 起始职级低 = 路更长（5 天），容错高（可被优化 3 次）
- 起始职级高 = 离老板更近，但对话更难、升职门槛更高
- 区域老板 = 速通挑战：仅 2 天、被优化 1 次即失败
- **注意**：`hr`（可玩 HR）与 `pu_rui_si`（普老板）是**两个独立角色**，身份、立绘、对话资源不得混用

### 1.2 角色专属技能文案

```
实习生 · 萌新光环
「新手保护期」——每场酒局第一次踩坑，对方会想"算了，新人嘛"

打工牛马 · 已读不回
「选择性失聪」——每场可跳过 1 次强制对话，代价是对方心里记一笔

设计师 · 五彩斑斓黑
「甲方听不懂的浪漫」——解锁隐藏创意选项，可能惊艳也可能翻车

程序员 · Debug
「肝是租来的」——清醒度下降减半，但社交能力也减半

销售冠军 · 话术王
「嘴上功夫」——好感增减 ×1.5，玩得好封神，玩不好社死加倍

HR · 背调
「信息差就是权力」——每场可查看对方一个隐藏属性

产品经理 · 需求变更
「我改我自己」——每场可推翻一次已选选项重选

老油条 · 太极推手
「二十年功力」——每场可将一个负面效果转嫁出去

区域老板 · 我请客
「钞能力」——强制买单，全场面子值 +20
```

## 4. 普老板隐藏线与终局

### 4.1 角色定位

| 项目 | 内容 |
|------|------|
| 姓名 | 普瑞斯（称"普老板"） |
| 资源 ID | `pu_rui_si` |
| 身份 | **隐藏最终 Boss**，非 HR、非可玩"区域老板" |
| 出现方式 | **不固定出现**，须满足隐藏条件才被解锁 |
| 与 `hr` 的关系 | 完全独立，不得混用立绘/对话/资源 |
| 与 `boss` 的关系 | `boss` 是可玩角色（区域老板），`pu_rui_si` 是隐藏 NPC |

### 4.2 隐藏触发条件

普老板**默认不出现**。玩家须在整局中满足以下条件之一，才会在**最终日**触发"普老板现身"事件，替代常规摊牌：

| 条件编号 | 名称 | 触发要求 | 设计意图 |
|---------|------|---------|---------|
| `C1` | 廉酒识人 | 累计选择"牛栏山二锅头"≥2 次，且尊严值 ≥ 70 | 你太有性格了，引起了她的注意 |
| `C2` | 硬骨头 | 全程选择"说人话/劳动法/拒绝"类硬刚选项 ≥ 4 次 | 有人看不惯你，也有人欣赏你 |
| `C3` | 猎头传闻 | 专业度 ≥ 40 且好感度 ≥ 80 | 名声传到了她耳朵里 |
| `C4` | 反向收购 | 路边摊/大排档 + 高尊严（≥ 80）+ 通关在望 | 隐藏线：直接当合伙人 |
| `C5` | 醉后真言 | 醉酒事件中选过"我想辞职很久了"，且最终未失败 | 她听到了你的真话 |

**触发判定时机**：最终日开始前（`StartDay` 阶段）

- 满足任一条件 → 最终日对手替换为 `pu_rui_si`，弹出专属登场文案
- 不满足 → 最终日走常规摊牌 `final_showdown`，**不出现普老板**
- 区域老板角色：`C1`-`C5` 条件放宽（因其本就身处高位），第 2 天有较高概率触发

### 4.4 普老板专属考核事件

按回合顺序轮换，不参与普通随机事件池。

#### `pu_strategy` — 战略考核

```
普老板没有碰酒杯："我看的是结果。给你一个季度，你怎么让这个项目活下来？"

A. 先核实现金流，给出里程碑和止损线      → 专业+8，好感+8，尊严+3
B. 您一句话，我保证翻十倍！              → 面子+5，好感-8，专业-3
C. 今晚先喝好，业务明天说                → 清醒-15，好感-10
D. 先砍一半人，数据自然好看              → 尊严-10，好感-5
```

#### `pu_accountability` — 责任考核

```
普老板放下一份亏损报告："供应商、团队、客户都说不是自己的错。你来负责，第一步做什么？"

A. 先承担协调责任，公开事实和补救计划    → 专业+6，好感+7，尊严+5
B. 这是前任留下的锅                      → 好感-8，尊严-5
C. 替团队罚三杯，别再问了                → 清醒-35，氛围+8，好感-5
D. 少汇报，先把报表修漂亮                → 好感-10，尊严-10
```

#### `pu_boundary` — 底线考核

```
普老板推开酒瓶："客户拿订单换一个不合规的承诺。今晚当着大家的面，你敢不敢拒绝？"

A. 守住合规底线，并给出可执行的替代方案  → 好感+8，专业+6，尊严+8
B. 先答应下来，以后再想办法              → 面子+8，好感-10，尊严-8
C. 都听您的，我不做决定                  → 好感-5，专业-3
D. 用喝酒把这个问题糊弄过去              → 清醒-20，氛围+5，好感-8
```

#### `pu_final_decision` — 终局问答（最后回合）

```
【终局】普老板合上文件："酒量不是任命书。最后一次回答：坐上这个位置，你愿意对谁负责？"

A. 对团队、客户和结果负责，用承诺和事实接受考核   → 专业+10，好感+10，尊严+5 【认可】
B. 只要您满意，其他都不重要                       → 好感-8，尊严-10
C. 对明确的目标负责，也接受失败时的问责           → 专业+8，好感+8，尊严+8 【认可】
D. 先喝完这杯，就算您答应了！                     → 清醒-30，好感-15
```

**通关判定**：终局选 A 或 C（`bossApproval = true`）→ 普老板认可 → 结算为"升职"且清醒度 > 0 → 记 `bossDefeated` → 达到 Lv.8 判 `win`。

### 4.5 通关与失败文案

```
【通关 · 普老板认可】
她站起身，把外套搭在手臂上，走到门口时停了一下：
```

## 5. 大话骰与情报系统

### 5.1 大话骰规则（总和制）

每回合开局插入一轮大话骰，决定**话语权归属**。

| 项目 | 规则 |
|------|------|
| 骰子 | 双方各 1 颗，玩家可见自己的点数，**对手点数隐藏** |
| 叫价 | 猜测**双方骰子总和**，范围 **2-12** |
| 流程 | 轮流行动：**加码**（叫比当前更大的数）或**叫开**（要求亮骰比对） |
| 判定 | 叫开时，若叫价 **>** 实际总和 → 叫开者赢（上家虚报）；否则叫开者输 |
| 兜底 | 加码超过 12 或已加码 5 轮，强制叫开，避免死循环 |

**话语权的影响**

| 结果 | 效果 |
|------|------|
| 玩家赢（获得话语权） | 好感 +5，且可**询问一个情报问题** |
| 玩家输（失去话语权） | 好感 -3，直接进入对话选择，需小心应对 |

**UI 文案**

| 时机 | 文案 |
|------|------|
| 开局提示 | "叫一个总和（2-12），或直接叫开" |
| 玩家叫价 | "你叫 {n}" |
| 对手叫价 | "对方叫 {n} · 轮到你了" |
| 玩家叫开 | "你叫开！" |
| 对手叫开 | "对方叫开！" |
| 揭晓（对手） | 对方骰面 + "实际总和 {sum}" |
| 玩家赢 | "你赢得话语权！可以问对方一个问题" |
| 玩家输 | "你失去了话语权 · 小心应对" |

### 5.2 情报问答

玩家赢得话语权后，每场最多问 **1 个**问题，获得对手性格与偏好的**隐晦片面**信息，供**次日**选酒/选菜/选场地参考。

**可选问题**

| ID | 问题 |
|----|------|
| `drink` | 今晚想喝点什么？ |
| `dish` | 有什么忌口或偏爱？ |
| `place` | 平时喜欢去哪儿吃？ |
| `person` | 您是个什么样的人？ |

**性格 × 答案对照**

#### 爱慕虚荣 `vain`

| 类别 | 回答 | 线索 |
|------|------|------|
| 酒 | "酒嘛，得看牌子。便宜的拿不出手。" | 偏好高价酒 |
| 菜 | "菜要够档次，摆盘也得讲究。" | 偏好高价菜 |
| 场地 | "环境最重要，路边摊就算了。" | 偏好高 Tier 餐厅 |
| 本人 | "场面上的事，不能含糊。" | 爱慕虚荣 |

#### 谦虚务实 `humble`

| 类别 | 回答 | 线索 |
|------|------|------|
| 酒 | "喝什么都行，别整那些虚的。" | 不在意酒价 |
| 菜 | "家常菜就挺好，别浪费。" | 偏好实在菜 |
| 场地 | "人多热闹的地方就行。" | 偏好低 Tier 餐厅 |
| 本人 | "我这人不讲究那些排场。" | 谦虚务实 |

#### 直爽豪迈 `blunt`

| 类别 | 回答 | 线索 |
|------|------|------|
| 酒 | "能喝的酒就是好酒。" | 偏好高度酒 |
| 菜 | "来点硬菜，别上那些花里胡哨的。" | 偏好硬菜 |
| 场地 | "哪都能喝，主要是跟谁喝。" | 不在意餐厅 |
| 本人 | "我这人说话直，你别介意。" | 直爽豪迈 |

#### 精明算计 `shrewd`

| 类别 | 回答 | 线索 |
|------|------|------|
| 酒 | "酒水利润高，懂行的不会乱点。" | 在意性价比 |
| 菜 | "点菜要看时令，反季的最贵。" | 偏好时令菜 |
| 场地 | "同样的菜，换个地方贵三倍。" | 偏好性价比餐厅 |
| 本人 | "钱要花在刀刃上。" | 精明算计 |

### 5.3 对手性格分配

| 对手 | 出场 Tier | 性格 |
|------|----------|------|
| 同事 `colleague` | T1 | 直爽豪迈 `blunt` |
| 直属领导 `leader` | T2 | 爱慕虚荣 `vain` |
| 客户 `client` | T3-T4 | 精明算计 `shrewd` |
| 普老板 `pu_rui_si` | 隐藏终局 | 精明算计 `shrewd` |

> **注**：普通对手性格实际来自**开局预生成的性格日程**（`personalitySchedule`），上表仅为角色默认值。普老板固定精明算计。

### 5.4 情报闭环（选对 → 加成）

情报**只在所指向的那一天有效**，过期作废。次日选择若符合对手偏好，触发加成：

| 判定 | 效果文案 | 数值 |
|------|---------|------|
| ✅ 投其所好 | "情报生效 · 投其所好（好感+6 氛围+5）" | 好感 +6、氛围 +5、面子 +3 |
| ❌ 没踩在点上 | "情报失准 · 没踩在点上（好感-4）" | 好感 -4、氛围 -3 |

**判定口径**

| 选择类型 | 高价档 | 低价档 |
|---------|-------|-------|
| 场地 | Tier 3-4 | Tier 1-2 |
| 酒 | 单价 ≥ ¥300 | 单价 < ¥300 |
| 菜 | 单价 ≥ ¥300 | 单价 < ¥300 |

**性格日程机制**

- 开局时预生成整局的每日性格序列
- 今日情报询问的是**明日对手**的性格 → 情报真的有预测价值
- 玩家需自行推断"该点贵酒还是便宜酒"，判断错了次日仍会吃亏

> **设计意图**：情报是"隐晦片面的"——只给线索不给答案。这套闭环让"赢得话语权"从单纯的好感奖励，变成**影响次日策略的真实信息优势**。

## 6. 文案增补规范

### 6.1 新增对话流程

1. 在本文档对应章节追加事件条目
2. 同步写入 `scripts/Data/GameData.lua` 的 `GameData.DialogEvents`
3. **不再**在 `游戏-酒桌文化v1.2.1.md` 中重复记录具体选项

### 6.2 事件数据结构

```lua
{
    id = "事件唯一ID",          -- 小写下划线，全局唯一
    type = "drink|dialogue|accident|drunk|final|boss",
    trigger = "any|internet|state|realestate|finance|game|media|pu_rui_si",
    text = "对方说的话",
    choices = {
        { text = "选项文案", effects = { favor = 5, sober = -10 } },
        -- 恰好 4 个选项
    },
}
```

### 6.3 文案写作准则

| 准则 | 说明 |
|------|------|
| 长度 | 单条选项 ≤ 20 字，事件文本 ≤ 40 字 |
| 语气 | 口语化，像真实对话，不像游戏选项 |
| 数值隐藏 | 文案中**绝不**出现"+5好感"这类数值提示 |
| 无歧义 | 不写"选这个"这类元叙述 |
| 幽默 | 保持讽刺但不说教，吐槽而非美化 |
| 安全 | 不涉及真实公司/人物/品牌商标 |

### 6.4 效果字段对照

| 字段 | 含义 | 范围 |
|------|------|------|
| `favor` | 好感度 | -20 ~ +20 |
| `dignity` | 尊严值 | -15 ~ +15 |
| `sober` | 清醒度 | -60 ~ +10 |
| `vibe` | 氛围值 | -10 ~ +15 |
| `face` | 面子值 | -10 ~ +8 |
| `pro` | 专业度 | -3 ~ +10 |
| `money` | 金钱 | 负数表示花费 |
| `bossApproval` | 普老板认可 | `true` / 省略 |
