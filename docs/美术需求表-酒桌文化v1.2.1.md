#### 独立素材与完成状态硬性要求

1. **独立 PNG**：角色、道具、背景、前景、UI皮肤、图标分别输出，不能用整屏效果图代替可组合的运行资源。透明类导出真实 Alpha，不用白底或棋盘格假装透明。
2. **UI无文字拆分**：按钮/对话框/面板/徽章底图不含姓名、台词、选项、天数、职级、金额、称号或拟声词；这些内容由运行时动态文本显示。九宫格需标注拉伸边界与安全内边距。
3. **角色完成定义**：`body/head/face/prop` 各层独立可开关，核心表情数量齐全、锚点一致、切换不跳变并通过合成验收，才可记“全套完成”。普老板使用同样分层标准；半身裁切不免除分层要求。
4. **状态分开记**：参考板 / 单张候选 / 待拆分 / 待表情 / 已验收运行素材分别记录。文件名含 `normal` 或 `v2` 不构成完成证明；完整合成预览只能作为附加验收图。

#### 适合 GPT 生图的资源与边界

- **先做P0**：普老板已有5张半身表情，后续补真分层并复核一致性；实习生核心表情；所需2个补充场景；7酒类与实际菜品清单图标；5属性图标、8职级徽章、无文字按钮/气泡皮肤。
- **后续批次**：其余角色/普通NPC仍按清单P0补齐；再制作P1/P2的无真实商标酒瓶、菜品详情、前置精英、称号底徽章、手绘FX单帧与装饰元素。角色差分需基于同一张定稿局部编辑并人工对齐，固定seed也不能保证一致性。
- **不直接当成生图成品交付**：PSD分层、body/head/face/prop拆分、九宫格参数、图集、逐帧一致性均需后期处理；文字通过UI渲染，序列帧通过动画制作或代码粒子实现，不能把单帧图标为整组完成。

## 1. 全局美术规范

### 1.1 风格锚点（Style Anchor）

**所有素材必须共享同一段风格描述**，这是保证视觉统一的关键。

> **核心风格句（2026-10-15 当前）**：
> 以用户参考图为准的日系精细手绘视觉小说风格，细腻有力度变化的线条，精致发丝与服装褶皱，正常修长的人物比例，黑灰米白基底，黄色与紫色重点点缀，克制的手绘阴影与纸感，保留职场讽刺和漫画情绪表现；独立运行素材不带设定板文字、不带整页排版。

**风格关键词表（当前执行）**：

| 维度 | 规范 | 反例（禁止） |
|------|------|-------------|
| 线条 | 日系精细手绘，轻重变化，保留细腻的发丝、衣褶与轮廓 | 旧版3-4px均匀粗描边、极简简笔画 |
| 上色 | 黑、灰、米白为基底，黄色与紫色为重点色 | 强制每人只用一种点缀色、全画面高饱和杂色 |
| 光影 | 克制的手绘明暗与材质细节，服装层次清晰 | 写实照片感、过度3D塑料高光 |
| 背景 | 场景手绘与人物协调；人物/UI等独立PNG使用透明底 | 将设定板纸底、文字、边框烘焙进立绘 |
| 表情 | 保留角色脸型与细腻五官，漫画情绪适度夸张 | 切换表情变脸、把全套表情压成一张不可拆板 |
| 比例 | 以用户图正常修长的人物比例为准 | 旧版1:2.5~1:3大头Q版作为主立绘 |

> **旧版风格归档**：原“黑白简笔线稿、3-4px均匀描边、90%黑白灰+10%单点彩色、无写实光影、1:2.5~1:3 Q版”已被覆盖。后文逐角色主体与附录仍含这些旧词时，只参考职业特征与道具，生成前必须用本节风格替换；不能将旧模板直接发包。

## 2. 角色立绘（9 个可玩角色）

### 2.1 立绘分层结构（关键！）

**每个角色按 4 层拆分**，便于表情差分与道具替换：

```
┌─────────────────────────────────────┐
│  Layer 4: 道具层 (prop)             │  ← 可替换（笔记本/键盘/名片夹）
├─────────────────────────────────────┤
│  Layer 3: 表情层 (face)             │  ← 可替换（6-8 套差分）
├─────────────────────────────────────┤
│  Layer 2: 头部层 (head)             │  ← 固定（发型/脸型）
├─────────────────────────────────────┤
│  Layer 1: 身体层 (body)             │  ← 固定（服装/姿态）
└─────────────────────────────────────┘
```

**分层技术要求**：

| 层 | 尺寸 | 锚点 | 说明 |
|----|------|------|------|
| body | 1024×1536 | 底部居中 | 含服装、姿态，不含头 |
| head | 512×512 | 与 body 颈部对齐 | 发型 + 脸型轮廓，五官留空 |
| face | 512×512 | 与 head 面部区对齐 | 仅眉毛/眼睛/嘴巴，透明底 |
| prop | 512×512 | 按需自由摆放 | 手持道具，独立可换 |

> **重要**：表情差分只画五官，**不要重画整张脸**，否则切换时会跳变。
