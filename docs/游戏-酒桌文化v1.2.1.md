# 《酒桌文化》游戏策划案

> **一句话概述**：一款以中国职场酒桌为背景的幽默策略对话游戏，玩家通过摇骰子、选对话、点菜、选酒，在荒诞的职场应酬中一路升职加薪，从实习生喝到当老板。

---

## 1. 游戏概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 《酒桌文化》 |
| 游戏类型 | 策略对话 / 骰子决策 / 多分支剧情 |
| 目标平台 | 移动端（竖屏/横屏均可，推荐横屏） |
| 美术风格 | 卡通讽刺风（黑色幽默插画 + 黄色/暖色调 UI） |
| 核心受众 | 18-35岁职场人群，社畜共鸣向 |
| 游戏时长 | 单局 5-8 分钟，高重玩性 |
| 调性定位 | **幽默解压、荒诞讽刺、会心一笑**（绝不贩卖焦虑） |

### 1.2 设计理念

- **笑着活下去**：用夸张荒诞的幽默消解职场压力，让玩家在游戏里"社死"比在现实中"社死"开心一万倍
- **每局不一样**：事件组合随机 + 多分支选择 = 极高重玩性
- **骰子是命运**：摇骰子不是纯随机，而是"命运加成"——你的选择影响骰子权重
- **社畜百态**：每个角色、每句台词都是职场人的"DNA动了"时刻

## 2. 核心玩法

### 2.1 游戏循环（核心 Loop）— 5天制

游戏总流程为 **5天**（工作日一周）。每场酒局 = 1天，但并非每天都有酒局——会随机触发"休息日"跳过一天。玩家从低职级起步，在有限的5天内尽可能升职，最终目标是**升到老板**。

```
┌───────────────────────────────────────────────────────────────┐
│  【首次开局】                                                  │
│  选择职场环境 → 选择初始角色（=初始职级）                      │
│       ↓                                                       │
│  ┌─────────────────────────────────────────────────────────┐  │
│  │ 【5天循环】                                              │  │
│  │                                                         │  │
│  │  第X天开始：                                            │  │
│  │  ├─ 正常酒局日：选饭局→选酒→点菜→回合对话→结算         │  │
│  │  └─ 随机休息日："你不会觉得每天都有酒局吧？"           │  │
│  │       → 跳过一天，职级不变，日期+1                      │  │
│  │                                                         │  │
│  │  酒局结算 → 判定升职/维持/降职/被优化 → 日期+1          │  │
│  │  → 保存进度 → 进入下一天                                │  │
│  └─────────────────────────────────────────────────────────┘  │
│       ↓                                                       │
│  【终局判定】（5天结束 或 提前触发）                           │
│  ├─ 🏆 升到"老板"职级 → 通关胜利！                           │
│  ├─ 💀 累计被优化 2-3 次 → 游戏结束（失败）                  │
│  └─ ⏰ 5天用完 → 根据最终职级评定结局                         │
└───────────────────────────────────────────────────────────────┘
```

#### 5天时间线规则

| 规则 | 说明 |
|------|------|
| 每天 = 1场酒局 或 1个休息日 | 无论结果如何，日期都 +1 |
| 随机休息日 | 第2-4天之间随机触发1次（概率30%），弹出文案"你不会觉得每天都有酒局吧？今天摸鱼休息！"，职级保持不变 |
| 5天结束 | 不管是否升到老板，都进入最终结算 |
| 提前通关 | 如果在第5天前就升到老板，立即通关（不用等5天） |
| 提前失败 | 累计被优化2-3次（根据起始职级调整），立即结束 |

#### 区域老板特殊规则（双局制）

选择**区域老板**角色时，游戏规则发生变化：

| 项目 | 普通角色 | 👔 区域老板 |
|------|----------|-------------|
| 总天数 | 5天 | **2天**（只需打2场酒局） |
| 起始职级 | Lv.1-5 | **Lv.7**（副总/合伙人） |
| 目标 | 升到 Lv.8 老板 | 同样升到 Lv.8（只差1级但极难） |
| 酒桌对手 | 随机同事/领导 | **第1天随机同事/领导，第2天必定Boss**（见下方） |
| 失败条件 | 被优化2-3次 | **被优化1次即失败** |
| 难度定位 | 正常 | 🔥 Hard Mode |

**区域老板的2天酒局安排**：

| 天数 | 对手 | 说明 |
|------|------|------|
| 第1天 | 随机同事/领导 | 与普通角色相同的随机对手池，但对话难度更高（Lv.7级别） |
| 第2天 | 🦈 大股东 或 👑 创始人/CEO（随机二选一） | **必定遭遇隐藏Boss**，决定最终命运 |

**隐藏Boss角色详情**：

| 对手 | 特点 | 酒桌风格 |
|------|------|----------|
| 🦈 大股东 | 掌握生杀大权，一句话决定你命运 | 高端白酒/洋酒，Tier 4场景，对话极其考验情商 |
| 👑 创始人/CEO | 传奇人物，格局极大 | 风格不定（可能路边摊也可能游艇），看重"气场"而非"排面" |

**设计意图**：
- 第1天是"热身局"，让玩家适应Lv.7难度的对话，同时积累面子值/好感度
- 第2天是"决胜局"，必定面对隐藏Boss，一局定生死
- 区域老板是"速通模式"/"挑战模式"，路径极短但容错为零，适合熟练玩家追求刺激

### 2.2 职级晋升系统

#### 职级阶梯（从低到高）

| 层级 | 职级 | 初始资金 | 解锁场景 | 描述 |
|------|------|----------|----------|------|
| Lv.1 | 🆕 实习生 | ¥500 | Tier 1 | 什么都不懂但什么都想学 |
| Lv.2 | 🐴 打工牛马 | ¥2000 | Tier 1 | 社畜本畜，卑微但有梗 |
| Lv.3 | 🎨 专业岗（设计/程序/销售等） | ¥5000-12000 | Tier 1-2 | 有一技之长 |
| Lv.4 | 📋 小组长/产品经理 | ¥8000 | Tier 2 | 开始管人了 |
| Lv.5 | 🧚 项目经理/主管 | ¥15000 | Tier 2-3 | 夹心饼干，上下都要哄 |
| Lv.6 | 📊 部门经理/总监 | ¥30000 | Tier 3 | 有实权了，但责任也大 |
| Lv.7 | 👴 副总/合伙人 | ¥50000 | Tier 3-4 | 距离顶峰一步之遥 |
| Lv.8 | 👔 **老板（通关）** | ¥100000 | Tier 4 | 🏆 恭喜通关！ |

#### 晋升/降职规则

每场酒局结算后，根据综合表现判定：

| 结果 | 条件 | 效果 |
|------|------|------|
| ⬆️ **升职** | 好感度高 + 面子足 + 没醉到失态 | 职级 +1，资金提升，解锁新场景 |
| ➡️ **维持** | 各项中等，没出大错也没亮点 | 职级不变，进入下一场酒局 |
| ⬇️ **降职** | 好感低 / 踩到雷区 / 表现差 | 职级 -1（最低到 Lv.1）|
| 💀 **被优化** | 严重失态 / 好感极低 / 醉到失控 | 优化计数 +1，职级 -1 |

#### 失败条件

| 角色类型 | 失败条件 |
|----------|----------|
| 普通角色（Lv.1-5起始） | 累计被优化 **3次** → 游戏结束 |
| 区域老板（Lv.7起始） | 被优化 **1次** → 游戏结束 |
| 所有角色 | **5天用完**未升到老板 → 根据最终职级评定结局（非失败，但非完美通关） |

#### 进度保存

每天结束后自动保存：

```
存档数据 = {
    职场环境,          -- 开局选择后固定不变
    当前角色,          -- 决定特殊能力和起始职级
    当前天数,          -- 1~5（区域老板为1~2）
    当前职级,          -- Lv.1 ~ Lv.8
    累计被优化次数,    -- 普通角色0/1/2，区域老板0
    已完成酒局数,      -- 实际打的酒局场次（排除休息日）
    累计金钱,          -- 总收入
    解锁的称号[],      -- 成就记录
    历史记录[],        -- 每天的简要结果（含休息日）
}
```

### 2.3 每日流程

每一天的流程：

```
第X天开始
    ↓
系统判定：今天是酒局日还是休息日？
    ↓
┌─ 休息日（随机触发，概率30%，第2-4天之间最多1次）──┐
│  弹出："你不会觉得每天都有酒局吧？"              │
│  → 显示摸鱼动画 → 职级不变 → 日期+1              │
└──────────────────────────────────────────────────┘
    或
┌─ 酒局日 ─────────────────────────────────────────┐
│  选择饭局场景（根据当前职级解锁不同Tier）          │
│      ↓                                            │
│  选酒（类型→品牌）→ 点菜                          │
│      ↓                                            │
│  ┌─────────────────────────────┐                  │
│  │ 循环回合（6-10回合/局）：    │                  │
│  │  双方摇骰子 → 触发事件      │                  │
│  │  → 对话选择（3-4选项）      │                  │
│  │  → 结算本回合影响           │                  │
│  └─────────────────────────────┘                  │
│      ↓                                            │
│  本局结算 → 升职/维持/降职/被优化                  │
└──────────────────────────────────────────────────┘
    ↓
日期+1 → 保存进度 → 判断是否终局
    ↓
├─ 已达5天 / 已通关 / 已失败 → 进入最终结算
└─ 否则 → 进入下一天
```

**关键设计**：
- 职场环境和角色在开局时选定，5天内**不再重选**
- 每个新酒局日只需要选择**饭局场地**和**酒水**
- 休息日是"喘息机会"，给玩家制造节奏变化和悬念（"还剩几天？够不够升职？"）
- 区域老板没有休息日（2天全是酒局，紧张刺激）
- 5天制让每一局选择都更有**紧迫感**和**策略权重**

### 2.4 骰子机制

每回合双方各摇一次骰子（玩家 + 对面的人）：

| 骰子组合 | 触发效果 |
|----------|----------|
| 玩家 > 对方 | 玩家掌握话语权，可以主动出击 |
| 玩家 < 对方 | 被动应对，需要圆场/接话 |
| 双方相同 | 触发"干杯事件"，强制饮酒并进入特殊对话 |
| 出现豹子（如66） | 触发稀有剧情事件（如老板突然打电话来） |

**隐藏机制**：玩家之前的选择会微调骰子概率（如选了茅台，"面子值"高，骰子略有加成）

### 2.5 对话选择系统

每次对话提供 3-4 个选项，风格分类：

| 风格类型 | 示例 | 效果倾向 |
|----------|------|----------|
| 🐴 职场马屁 | "张总这格局，我学一辈子都学不来" | +好感度，-尊严值 |
| 🔥 阴阳怪气 | "可不嘛，毕竟您工资是我十倍" | -好感度，+尊严值，可能触发隐藏线 |
| 🧠 行业黑话 | "这个我们要拉齐一下颗粒度" | +专业度，对方可能懵逼 |
| 🍺 酒桌套路 | "感情深一口闷，感情浅舔一舔" | +氛围值，-清醒度 |
| 😶 沉默摸鱼 | "嗯嗯，对对对，您说得对" | 中性，保命但无功无过 |
| 💀 整活发疯 | "不好意思，我要去厕所哭一会儿" | 随机效果，可能大加分或直接结束 |

### 2.6 数值系统

#### 核心属性（隐藏，结算时揭晓）

| 属性 | 说明 | 影响 |
|------|------|------|
| 好感度 | 对方对你的印象 | 直接影响结局走向 |
| 尊严值 | 你还剩多少自我 | 影响结局称号和隐藏剧情 |
| 清醒度 | 你还能正常说话吗 | 低于阈值触发"醉酒模式"（选项变乱） |
| 氛围值 | 饭局整体气氛 | 影响事件触发概率 |
| 面子值 | 场面功夫做得如何 | 受选酒、选餐厅影响 |

#### 金钱系统

- 初始资金根据角色不同（打工人 ¥2000 vs 区域老板 ¥50000）
- 选餐厅、选酒、点菜都要花钱
- **钱花得多不一定好**（可能被认为"不会过日子"或"太装"）
- **钱花得少也不一定差**（可能被认为"务实"或"抠门"）
- 结算时剩余金额影响评分

## 3. 内容系统

### 3.1 职场环境（大地图）

玩家开局选择所在的职场环境，不同环境有不同的NPC风格、对话库和判定标准：

| 环境 | 特色 | 酒桌风格 | 加薪难度 |
|------|------|----------|----------|
| 🏛️ 国企/央企 | 讲究排面、论资排辈 | 白酒文化，敬酒有严格顺序 | ★★★★☆ |
| 💻 互联网大厂 | 内卷、黑话多、变化快 | 啤酒/鸡尾酒，氛围相对松 | ★★★☆☆ |
| 🏗️ 地产/基建 | 豪爽、酒量是入场券 | 白酒为主，必须能喝 | ★★★★★ |
| 🎬 广告/传媒 | 创意至上、social能力 | 红酒/洋酒，讲调性 | ★★★☆☆ |
| 🏦 金融/银行 | 高端、保守、重关系 | 高端白酒/洋酒，讲品位 | ★★★★☆ |
| 🏭 制造业/工厂 | 实在、直来直去 | 啤酒/白酒，量大管饱 | ★★☆☆☆ |
| 🎮 游戏公司 | 宅、社恐多、加班狠 | 啤酒/气泡水，可能有人点可乐 | ★★☆☆☆ |
| 🏥 体制内医院/学校 | 稳定、关系复杂 | 白酒，暗流涌动 | ★★★★☆ |
| 📱 创业公司 | 画饼、鸡血、不确定性 | 什么便宜喝什么 | ★☆☆☆☆（但可能拿期权） |

### 3.2 初始角色（决定起始职级与特殊能力）

玩家开局选择角色，决定**起始职级**和**贯穿全程的特殊能力**。资金由当前职级决定（见 2.2 职级阶梯），角色不影响资金。

| 角色 | 起始职级 | 特殊能力（全程有效） | 描述 | 晋升难度 |
|------|----------|----------------------|------|----------|
| 🆕 实习生 | Lv.1 | "萌新光环"：每场酒局第一次失误不扣好感 | 什么都不懂但什么都想学 | ★☆☆☆☆（路最长但容错高） |
| 🐴 打工牛马 | Lv.2 | "已读不回"：每场可跳过一次强制对话 | 社畜本畜，卑微但有梗 | ★★☆☆☆ |
| 🎨 设计师 | Lv.3 | "五彩斑斓黑"：对话中可解锁隐藏创意选项 | 需求听不懂但画得出来 | ★★★☆☆ |
| 🔧 程序员 | Lv.3 | "Debug"：清醒度下降速度减半 | 高薪但社恐，喝多了可能写代码 | ★★★☆☆ |
| 🎤 销售冠军 | Lv.3 | "话术王"：好感度增减幅度 ×1.5 | 能把梳子卖给和尚，也能把自己喝进医院 | ★★★☆☆ |
| 📊 HR | Lv.3 | "背调"：每场可查看对方一个隐藏属性 | 笑里藏刀，信息就是武器 | ★★★☆☆ |
| 📋 产品经理 | Lv.4 | "需求变更"：每场可推翻一次已选选项重选 | 永远在改需求，包括改自己说过的话 | ★★★★☆ |
| 👴 老油条 | Lv.5 | "太极推手"：每场可将一个负面效果转嫁 | 在公司活了二十年的终极形态 | ★★★★★ |
| 👔 **区域老板** | **Lv.7** | "我请客"：可强制买单提升全场面子值+20 | 🔥 Hard Mode：仅2天，对手为大股东/CEO | ★★★★★★（极难） |

**设计意图**：
- 起始职级低 = 路更长（5天），但容错率高（可被优化3次）
- 起始职级高 = 离老板更近，但对话难度更高、对手更强、升职条件更苛刻
- **区域老板** = 速通挑战模式：仅2天、仅2场酒局、对手为隐藏Boss、被优化1次即失败
- 特殊能力贯穿全程，是角色差异化的核心体验

## 4. 结局系统

### 4.1 单局结算（每场酒局结束后）

每场酒局结束后根据综合属性判定**本局结果**，影响职业晋升进度：

| 结果 | 条件 | 表现 | 职级影响 |
|------|------|------|----------|
| ⬆️ 升职加薪 | 好感高 + 面子足 + 没醉到失态 | "恭喜你，下周一去新部门报到" | 职级 +1 |
| ➡️ 维持现状 | 各项中等，没出大错 | "这顿饭...好像白吃了" | 不变 |
| ⬇️ 表现不佳 | 好感低 / 踩到雷区 | "最近状态不太好啊..." | 职级 -1 |
| 💀 被优化 | 严重失态 / 好感极低 / 醉到失控 | "明天来HR办公室一趟" | 职级 -1，优化计数 +1 |

### 4.2 终局（游戏结束条件）

| 终局类型 | 触发条件 | 结算画面 |
|----------|----------|----------|
| 🏆 **通关胜利** | 升到 Lv.8 老板（可提前） | "恭喜！你从一个小实习生喝成了老板！" |
| 💀 **永久优化** | 累计被优化达上限（普通3次/区域老板1次） | "您已被永久移出职场群聊，感谢您的付出" |
| ⏰ **5天用完** | 5天结束但未升到老板 | 根据最终职级评定（见下方） |
| 🦅 **隐藏通关：反向收购** | 牛栏山+路边摊+尊严值满 | "你太有性格了，直接当合伙人！"（跳到 Lv.8） |
| 📞 **隐藏通关：被猎头挖走** | 专业度满+尊严值高 | "隔壁桌猎头看中你了，薪资翻三倍"（跳升2级） |

#### ⏰ "5天用完"结局评定

当5天（区域老板为2天）用完但未通关时，根据**最终职级**与**起始职级**的差值评定：

## 9. 技术实现要点

### 9.1 架构建议

```
scripts/
├── main.lua              -- 入口，场景管理
├── Game/
│   ├── GameManager.lua   -- 游戏状态机（选择→游戏→结算）
│   ├── DiceSystem.lua    -- 骰子逻辑+权重计算
│   ├── DialogSystem.lua  -- 对话树+分支管理
│   └── ScoreSystem.lua   -- 属性计算+结局判定
├── Data/
│   ├── Events.lua        -- 事件数据库
│   ├── Dialogues.lua     -- 对话数据库
│   ├── Items.lua         -- 酒水/菜品数据
│   └── Characters.lua    -- 角色数据
├── UI/
│   ├── MainMenu.lua      -- 主菜单
│   ├── GameHUD.lua       -- 游戏内HUD
│   ├── DialogPanel.lua   -- 对话选择面板
│   ├── DiceAnimation.lua -- 骰子动画
│   └── ResultScreen.lua  -- 结算界面
└── Utils/
    └── SaveManager.lua   -- 存档/排行榜
```

### 9.2 关键技术点

- **对话系统**：使用数据驱动的对话树，支持条件分支
- **骰子动画**：NanoVG 或 3D 骰子模型 + 物理模拟
- **UI系统**：使用 urhox-libs/UI 组件库
- **数据存储**：云变量保存排行榜，本地保存解锁进度
- **随机性**：种子随机+权重系统，保证体验公平但不完全重复
