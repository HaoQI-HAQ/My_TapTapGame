## 1. 项目概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 五盏酩酊 |
| 游戏类型 | 互动叙事 / 元叙事恐怖 / 解谜冒险 |
| 目标平台 | 移动端（TapTap）、PC |
| 目标受众 | 18-30岁，喜爱悬疑恐怖、独立叙事游戏的玩家 |
| 游戏时长 | 单次通关 15-25 分钟 |
| 引擎 | UrhoX (TapTap制造) |

### 1.2 一句话描述

**手机突然被黑，界面上多了一款叫「口袋酒鬼」的 app——每喝一盏，你离真相更近一步，也离清醒更远一步。**

### 1.3 核心体验关键词

- 🍶 醉酒递进（感知逐渐失控）
- 📱 元叙事（打破第四面墙，"这是你的手机"）
- 🔍 碎片拼凑（真相藏在细节里）
- 😰 心理压迫（越清醒越恐惧）

## 2. 世界观与故事

### 2.1 核心设定

玩家打开手机，发现：
1. 屏幕曾短暂黑屏（"被黑了"）
2. 桌面上多了一个从未安装过的 app：**「口袋酒鬼」**
3. 这个 app 的图标是一个醉倒的卡通小人，旁边写着"来一盏？"

打开「口袋酒鬼」后，界面显示：

```
┌────────────────────────┐
│     🍶 口袋酒鬼        │
│                        │
│   "每一盏都是一段记忆"  │
│                        │
│   ○ ○ ○ ○ ○           │  ← 五个酒盏（空）
│                        │
│   [ 斟 满 第 一 盏 ]   │
│                        │
│   当前状态：清醒        │
└────────────────────────┘
```

每"喝"一盏酒，就会解锁一段被隐藏的记忆/真相。同时，手机界面会随着"醉酒程度"逐渐扭曲变形。

### 2.2 背景故事（完整剧情）

**真相（玩家逐步揭开）：**

主角是一个普通大学生。一周前的酒局上，主角在醉酒后做了一件自己无法接受的事——在酒桌上被怂恿后，将好友的秘密当众说出，导致好友"阿酒"的生活彻底崩塌。

事后主角陷入深度自责，潜意识选择性遗忘了整个酒局。「口袋酒鬼」app 是阿酒写的——他是个程序员，在消失前给主角的手机远程推送了这个 app。

阿酒的目的：**不是报复，而是想让主角记起来，然后做出选择——面对，还是继续逃。**

### 2.3 人物设定

| 角色 | 身份 | 关键信息 |
|------|------|---------|
| 主角（玩家） | 大学生，记忆缺失 | 第一人称 |
| 阿酒 | 主角室友兼好友，程序员 | 「口袋酒鬼」app的开发者 |
| 老郑 | 酒局组织者，学长 | 怂恿主角说出秘密的人 |
| 小叶 | 主角女朋友 | 目睹了酒局全过程 |

## 3. 核心玩法设计

### 3.1 五盏结构（主线推进）

游戏以**五盏酒**作为五个章节的推进结构：

| 盏数 | 章节名 | 内容主题 | 醉酒等级 | 时长 |
|------|--------|---------|---------|------|
| 第一盏 | 「微醺」 | 酒局的邀请 | 5% | 3分钟 |
| 第二盏 | 「微醺偏上」 | 酒桌上的氛围 | 25% | 4分钟 |
| 第三盏 | 「半醉」 | 被怂恿的瞬间 | 50% | 5分钟 |
| 第四盏 | 「烂醉」 | 说出秘密的那一刻 | 80% | 5分钟 |
| 第五盏 | 「酩酊」 | 真相全貌与最终选择 | 100% | 5分钟 |

### 3.2 每盏的玩法循环

```
点击"斟满第 N 盏"
    ↓
播放斟酒动画（酒液倒入杯中）
    ↓
屏幕模拟"喝下"效果（画面晃动/模糊/变暖）
    ↓
进入记忆碎片场景
    ↓
在场景中探索信息（点击/滑动/选择）
    ↓
发现关键线索 → 触发剧情推进
    ↓
记忆碎片结束，返回「口袋酒鬼」主界面
    ↓
酒盏填满一个，醉酒等级提升
    ↓
手机界面出现更多异常
```

### 3.3 交互方式

#### A. 记忆碎片中的交互

| 交互类型 | 操作 | 示例 |
|---------|------|------|
| 点击探索 | 点击画面中的物品/人物 | 点击酒瓶 → 显示品牌和度数 |
| 滑动翻阅 | 左右滑动查看聊天记录 | 酒局前的群聊 |
| 选择对话 | 在关键节点做选择 | "再喝一杯？" → 喝/不喝 |
| 拼图还原 | 将碎片信息拼在一起 | 还原撕碎的照片 |
| 倒叙查看 | 某些信息需要倒着读 | 醉酒后写的日记（字序颠倒） |

#### B. 手机界面中的交互

| 功能 | 说明 |
|------|------|
| 查看通知 | 随章节推进，弹出异常通知 |
| 回看聊天 | 手机消息app中可找到与阿酒的对话 |
| 检查相册 | 酒局照片逐渐"恢复" |
| 查看通话记录 | 发现未接来电和异常号码 |

### 3.4 醉酒系统（核心视觉机制）

**醉酒等级影响所有界面表现：**

| 醉酒等级 | 视觉效果 | 交互影响 | 叙事影响 |
|---------|---------|---------|---------|
| 0%（清醒） | 界面完全正常 | 正常操作 | 只能看到表面信息 |
| 5%（微醺） | 轻微暖色调偏移 | 正常 | 开始出现模糊的记忆碎片 |
| 25% | 文字轻微晃动，边缘柔化 | 按钮位置微偏 | 记忆变得更清晰 |
| 50% | 画面周期性摇晃，重影出现 | 点击需要更精准 | 核心记忆浮现 |
| 80% | 严重色彩失真，文字重叠 | 界面逻辑开始混乱 | 真相的冲击画面 |
| 100% | 全屏扭曲→突然清醒（或彻底黑屏） | 取决于结局 | 完整真相 |

#### 视觉效果实现

```
第一盏效果：
- 屏幕色温 +5%（偏暖）
- 偶尔轻微晃动（振幅1px）

第二盏效果：
- 色温 +15%
- 文字出现随机 1px 偏移
- 背景图片轻微模糊（高斯 1px）

第三盏效果：
- 色温 +25%
- 画面每 3 秒晃动一次（振幅 3px）
- 出现轻微重影（透明度 20%）
- 部分文字开始颠倒

第四盏效果：
- 画面持续缓慢旋转（±2度）
- 严重重影（透明度 50%）
- 文字大面积乱码/重叠
- 颜色通道分离（RGB偏移）
- 通知栏数据异常（时间显示错误）

第五盏效果：
- 画面极度扭曲 → 然后...
- 结局A：画面突然变得无比清晰（宿醉后的清醒）
- 结局B：彻底黑屏，只剩文字
- 结局C：画面恢复，但一切信息都消失了
```

## 4. 详细章节设计

### 4.1 第一盏「微醺」——酒局的邀请

**解锁条件**：游戏开始自动可用

**记忆内容**：
- 一周前，群聊里老郑发了消息："周五晚上聚一下？老地方，不醉不归"
- 主角回复："行，几点？"
- 阿酒回复："我就不去了吧...最近心情不好"
- 老郑：" 来来来，喝点酒就好了"
- 主角：" 一起去呗，好久没聚了"
- 阿酒：" ...好吧"

**交互设计**：
1. 打开后看到一个模糊的群聊界面
2. 向上滑动可以查看更多消息
3. 点击阿酒的头像，弹出他的状态："最近在想一些事情"
4. 找到关键信息后，章节结束

**线索获取**：
- 🔑 阿酒最近心情不好（伏笔）
- 🔑 老郑是组局者

**返回后手机异常**：
- 通知栏多了一条推送："你确定要继续想起来吗？"（点击后消失）

---

### 4.2 第二盏「微醺偏上」——酒桌上的氛围

**解锁条件**：完成第一盏

**记忆内容**：
- 场景：烧烤摊，四个人坐在一起
- 画面模糊，但能听到对话
- 老郑在起哄，不断给大家倒酒
- 阿酒喝了很多，说话开始不清楚
- 小叶在旁边看手机，偶尔看一眼主角
- 老郑突然说："诶，阿酒，你那个事...到底是真的假的啊？"
- 阿酒沉默
- 老郑转向主角："你室友你还不知道？给大家说说呗"

**交互设计**：
1. 画面是一张带模糊的酒桌照片
2. 点击不同位置出现对话气泡
3. 点击酒瓶：显示已经喝了3瓶
4. 点击阿酒：他低着头，不说话
5. 点击老郑：他笑着看你，"来，再干一杯，然后给大家讲讲"
6. **选择出现**："要不要再喝一杯？"
   - 喝 → 进入下一阶段
   - 不喝 → "你已经喝了。这是记忆，不是现在。" → 强制推进

**线索获取**：
- 🔑 阿酒有一个"秘密"
- 🔑 老郑知道这个秘密并在起哄
- 🔑 小叶全程在场

**返回后手机异常**：
- 相册里多了一张酒局照片（模糊不清）
- 消息app中出现一条未读消息（发送者：阿酒，内容："...."）

---

### 4.3 第三盏「半醉」——被怂恿的瞬间

**解锁条件**：完成第二盏

**记忆内容**：
- 主角的视角已经开始晃动（第一人称）
- 老郑连续敬了三杯酒
- 老郑："来嘛，反正大家都是兄弟，说出来又怎样"
- 主角的内心独白（文字）："我不应该说的..."
- 老郑："他自己都不在意，你紧张什么"
- 主角看了一眼阿酒——阿酒醉得趴在桌上了
- 老郑："他都睡了，听不到的，说嘛"
- ...
- **画面突然黑屏**
- 出现文字："你说了。"

**交互设计**：
1. 画面是第一人称视角，晃动越来越剧烈
2. 老郑的对话以弹幕形式从右飘到左
3. 每一句话都在施加压力（倒计时进度条）
4. 玩家可以点击"拒绝"按钮——但按钮越来越小
5. 最终按钮小到无法点击 → 强制推进
6. 黑屏后只有一行白字："你说了。"

**设计意图**：
- 让玩家体验"被怂恿"的无力感
- 缩小的按钮 = 逐渐消失的理性
- 这不是选择题，是对记忆的还原——你当时没能拒绝

**线索获取**：
- 🔑 主角在醉酒后说出了阿酒的秘密
- 🔑 阿酒当时看似睡着了

**返回后手机异常**：
- 手机壁纸自动变成了一张深色图片
- 消息app中阿酒的对话框显示"对方正在输入..."（永远不会发出）
- 通知："你还有两盏。要继续吗？"

---

### 4.4 第四盏「烂醉」——说出秘密的那一刻

**解锁条件**：完成第三盏

**记忆内容**：
- **核心场景**：主角说出秘密的完整过程
- 主角（醉酒状态，声音模糊）："阿酒他...其实..."
- 具体内容用**消音/马赛克处理**——玩家只能看到在场者的反应
- 小叶震惊地看着主角
- 老郑大笑
- 桌对面——阿酒的眼睛是睁开的。他没有睡。他全听到了。
- 主角和阿酒四目相对
- 阿酒站起来，一句话没说，走了
- 主角愣在原地

**交互设计**：
1. 画面严重扭曲，只能看到模糊的人影
2. 主角说话的内容是**乱码文字**（代表玩家无法直面说出的内容）
3. 点击乱码 → 文字短暂清晰 → 立刻又乱掉
4. 唯一清晰的画面：阿酒睁开的眼睛
5. 阿酒起身离开的画面以**慢动作**播放
6. 整个过程没有 BGM，只有心跳声和环境噪音

**情感设计**：
- 秘密内容不公开 = 留给玩家想象空间（更有冲击力）
- 阿酒没有睡着 = 核心反转
- 沉默离开比任何愤怒都更让人窒息

**线索获取**：
- 🔑 阿酒全程清醒，听到了一切
- 🔑 阿酒选择沉默离开
- 🔑 小叶见证了全过程（解释为什么之后态度变了）

**返回后手机异常**：
- 手机界面严重故障
- 阿酒的聊天记录中多了一条新消息（时间戳是一周前）：
  "我不怪你。但我需要你记住。"
- 通话记录中出现阿酒的未接来电（7天前，凌晨3:41）

---

### 4.5 第五盏「酩酊」——真相全貌与最终选择

**解锁条件**：完成第四盏

**记忆内容**：
- 这不是一段新的记忆，而是**阿酒的留言**
- 「口袋酒鬼」app变成了一封信的界面
- 阿酒的话（逐字显示）：

> "你可能不记得那天晚上发生了什么。
> 
> 你喝多了，但那不是借口。
> 
> 我写了这个 app，不是为了报复你。
> 我只是想让你**记住**。
> 
> 记住你做了什么，然后——自己决定接下来怎么做。
> 
> 我会消失一段时间。不是因为恨你。
> 是因为我需要时间。
> 
> 这五盏酒，是我请你喝的。
> 喝完之后，一切都该清醒了。
> 
> —— 阿酒"

**最终选择**（决定结局）：

信的末尾出现三个选项——

```
[ 给阿酒发一条消息 ]
[ 删除「口袋酒鬼」 ]
[ 什么都不做 ]
```

## 5. 结局设计

### 5.1 三个结局

| 结局 | 触发条件 | 内容 |
|------|---------|------|
| **A. 面对** | 选择"给阿酒发一条消息" | 画面恢复清晰。消息app打开，光标闪烁。玩家输入任意文字发送（系统不限制内容）。发送后画面显示"已发送"，然后：「口袋酒鬼」app图标变灰，下方出现小字："希望下次见面，是清醒的。" 结束。 |
| **B. 逃避** | 选择"删除口袋酒鬼" | 确认删除弹窗："确定要忘记吗？" → 确定。app被删除，手机恢复正常。一切异常消失。但在最后一帧：通知栏闪过一条极快的消息——"...下次你不会这么幸运了。" 结束。暗示记忆可能再次找上门。 |
| **C. 停滞** | 选择"什么都不做" | 画面静止10秒。然后屏幕缓慢暗下去。最后只剩「口袋酒鬼」的图标在黑暗中微微发光。底部出现文字："第六盏，留给下一次。" 结束。暗示主角陷入了循环。 |

### 5.2 隐藏结局

| 结局 | 触发条件 | 内容 |
|------|---------|------|
| **D. 回溯** | 在第三盏中成功点击缩小的"拒绝"按钮（极难） | 画面闪白——"这不是发生过的事。但也许...在另一个时间线里。" 回到「口袋酒鬼」主界面，五个酒盏全部碎裂。阿酒的消息："谢谢你愿意选择不同的路。但这次，你需要面对已经发生的。" 然后回到正常第四盏流程。这个结局不改变故事，但解锁一个"如果"彩蛋。 |

## 6. 美术与视觉风格

### 6.1 整体风格

| 维度 | 描述 |
|------|------|
| 基调 | 暗色手机界面 + 暖色醉酒滤镜 |
| 记忆场景 | 水彩/半透明风格（模糊朦胧感） |
| 配色主色 | 深蓝底 + 琥珀色（酒色）强调 |
| Glitch风格 | 暖色噪点（区别于冷色科技故障） |

### 6.2 「口袋酒鬼」App UI 设计

```
色彩方案：
- 背景：深木色 (#2C1810)
- 主色：琥珀金 (#D4A843)
- 辅色：米白 (#F5E6D3)
- 警告：暗红 (#8B1A1A)

图标风格：
- 一个Q版醉酒小人倒在酒杯旁
- 酒杯中液体根据进度填充

字体：
- 标题：手写风格（像是酒后潦草写的）
- 正文：普通sans（对比营造氛围）
```

### 6.3 醉酒视觉效果表

| 效果 | 技术实现 |
|------|---------|
| 暖色偏移 | 整体 Hue +15°，Saturation +20% |
| 画面晃动 | sin波驱动的translate偏移 |
| 模糊 | 高斯模糊 (0→8px 递进) |
| 重影 | 叠加半透明偏移副本 |
| 文字扭曲 | 字符级别随机偏移+旋转 |
| RGB分离 | R/G/B 通道分别偏移 1-3px |
| 呼吸感 | 整体 scale 在 0.98-1.02 间缓动 |

## 7. 音频设计

### 7.1 环境音效

| 场景 | 音效 |
|------|------|
| 「口袋酒鬼」主界面 | 安静酒吧环境音（远处低语、杯碟声） |
| 斟酒动画 | 液体倒入玻璃杯的声音 |
| 喝下效果 | 吞咽声 + 心跳加速 |
| 记忆碎片内 | 对应场景环境音（烧烤摊嘈杂声） |
| 手机异常 | 电流杂音/系统错误音 |

### 7.2 BGM

| 阶段 | 风格 |
|------|------|
| 第一盏 | 安静的吉他finger picking |
| 第二盏 | 轻微失真的环境音乐 |
| 第三盏 | 低频压迫 + 心跳声 |
| 第四盏 | 几乎无音乐，只有心跳和呼吸 |

## 11. 差异化与创新点

### 11.1 与同类游戏的区别

| 对比维度 | 常见手机模拟恐怖游戏 | 《五盏酩酊》 |
|---------|-------------------|-------------|
| 恐怖来源 | 超自然/灵异事件 | **现实人际关系的创伤** |
| 视觉扭曲原因 | 病毒/鬼魂 | **醉酒（有物理逻辑的）** |
| 玩家角色 | 调查者/旁观者 | **事件的当事人/加害者** |
| 情感基调 | 恐惧 | **愧疚 → 自省 → 选择** |
| 叙事目的 | 揭露他人真相 | **面对自己做过的事** |

### 11.2 核心创新

1. **醉酒作为叙事工具** — 不是恐怖效果，而是"记忆还原"的合理化解释
2. **玩家=加害者** — 罕见的视角：你不是在调查别人的错，而是面对自己的错
3. **无法改变的过去** — 第三盏中缩小的按钮代表"你当时确实没能拒绝"
4. **不是报复，是期待** — 阿酒的动机颠覆玩家预期

## 12. 风险评估

| 风险 | 等级 | 应对方案 |
|------|------|---------|
| 剧情单薄（48h作品体量） | 中 | 通过视觉/音频/交互弥补文本量不足 |
| 醉酒效果引发不适 | 中 | 提供"降低视觉效果"选项 |
| 主题敏感（酒桌文化/PUA） | 低 | 保持批判视角，不美化劝酒行为 |
| 流程太短缺乏记忆点 | 中 | 第三盏的"缩小按钮"设计制造讨论度 |
| 结局缺乏后劲 | 低 | 结局C的"第六盏"暗示制造余韵 |
